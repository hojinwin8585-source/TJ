# P15. 직업 놀이: 옷 입고 직접 일해 보기

**권장 모델**: 오퍼스 (그림과 놀이를 새로) · **앞 단계**: P0, P12-가, P2-가(꾸미기 규칙과 `makeTool`)

> 쓰는 환경에 `gptaku` 스킬(또는 깊은 검색 스킬)이 있으면 먼저 불러서, 비슷한 유아 앱이 이 화면을 어떻게 만드는지 확인한 뒤 시작하세요. 없으면 그냥 진행합니다.

## 왜
통합판의 직업 옷 입히기는 옷만 입히고 끝나 허술합니다. 옷을 입으면 그 일을 직접 해 보게 합니다.

## 먼저 읽을 것
`설계/config.json`의 `games.jobs`, `flow`, `rules`, `touch.tool`, `calm.characterLife`, `salon.js`(꾸미기와 도구 본보기), 통합판에서 옮긴 직업 화면

## 할 일
1. **흐름** (`games.jobs.flow`): 직업 카드 3장 → 옷 3가지 입히기(붙이기·떼기·바꾸기, 이름을 두 언어로) → 거울 → 출동 → 일 해 보기 → 고마워 → 진짜 사진 카드 → 도장.
2. **일 해 보기** (`jobs[].mission`): 도구가 손가락을 따라오고(`ML.P2.makeTool`) 닿은 곳만 바뀜. 소방관은 물줄기로 불 끄기, 의사는 청진기와 반창고 등. 1단계는 소방관과 의사.
3. 옷과 도구 그림은 말랑 그림체로 새로(`art.js`의 `ART.JOB`). 도구는 `touch.tool` 크기.
4. 캐릭터와 도와주는 대상(불난 집의 고양이, 아픈 곰)은 `ML.Alive`로 살아 있게.
5. 단계 1~5(`levels`). 2단계의 "다른 직업 옷 골라내기"는 틀려도 "이건 요리사 모자야!" 하고 알려 주고 다시.
6. 예전 직업 놀이(`jobdress`, `jobmatch`, `dispatch`)의 타일은 이 놀이로 연결하고 코드는 남겨 둠.

## 완료 기준 (`tests/jobs.js`)
소방관: 옷 3가지를 입히기 전에는 출동이 안 됨 · 물줄기가 닿은 불만 작아지고 3곳을 다 꺼야 끝남(만든 만큼 쓰기 규칙과 같은 원리) · 글자 버튼 없음 · 2단계에서 다른 직업 옷을 누르면 붙지 않고 이름을 말해 줌 · `rules`, `audit`, `monkey` 통과.

## 끝나고 알려 줄 것
직업별 캡처(옷 입히기, 일 해 보기), 아직 못 만든 직업.
