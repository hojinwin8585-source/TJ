# P4. 우리 가족 얼굴

**권장 모델**: 쏘넷 · **대상**: 얼굴 관리 화면, 동물 미용실 4단계 · **앞 단계**: P2

## 왜
아이 얼굴, 엄마, 삼촌, 할머니 얼굴이 캐릭터로 나오면 아이가 훨씬 좋아합니다.

## 먼저 읽을 것
`설계/config.json`(`cast`), `index.html`의 `CAST`·`pickPhoto`·사진 자르기(`#cropper`)·친구들 화면(`games.friends`), `salon.js`

## 할 일
1. **얼굴 자리 7개** (`cast.slots`): 지금의 주인공·엄마·아빠 자리에 삼촌, 할머니, 직접 이름 붙이는 자리 2개를 더합니다. 저장 형식은 기존 것을 그대로 읽을 수 있게.
2. **어른용 얼굴 관리 화면**: 어른 확인 뒤 들어감. 자리마다 사진 넣기(찍기 또는 고르기) → 동그랗게 맞추기(기존 기능) → 부를 이름. 지우기.
3. **얼굴 캐릭터 그리기**: `ART.person(photo, opt)`를 `art.js`에 추가. 동그란 사진 얼굴 + 그린 몸(둥근 어깨와 옷) + 그린 머리 장식 자리. 외곽선과 그림자는 `스타일견본.html` 그림체. 사진이 없는 자리는 쓰지 않습니다.
4. **미용실 4단계**: 손님으로 가족 얼굴 캐릭터가 옵니다. 사람 손님은 진흙 대신 "머리 감기"로: 거품 → 헹굼 → 말림은 같고, 꾸미기 카드도 같습니다. 인사말은 "할머니가 오셨어요! Grandma is here!"처럼 이름으로.
5. **칭찬에 얼굴**: 한 판이 끝나면 넣어 둔 얼굴 중 하나가 작게 나와 손뼉 치는 장면(3초). 사진이 하나도 없으면 토토가 대신.
6. 사진은 기기에만 저장됨을 관리 화면에 한 줄로 적습니다. 저장 공간이 모자라면 알려 줍니다(기존 방식).

## 바꾸지 말 것
공주 모험의 주인공 사진 기능. 사진 크기 256px.

## 완료 기준
1. 테스트용 그림 파일로 할머니 자리에 사진을 넣고, 미용실 4단계에서 할머니가 손님으로 나오는 것을 확인.
2. 사진이 하나도 없어도 4단계가 오류 없이 동물 손님으로 진행.
3. 예전에 저장된 얼굴 데이터가 그대로 보임.
4. `tests/audit.js`, `tests/monkey.js` 통과.

## 끝나고 알려 줄 것
얼굴 캐릭터 캡처, 실제 사진으로 사람이 확인해야 할 것(얼굴 맞추기 편한지).
