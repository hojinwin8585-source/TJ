# P4. 우리 가족 얼굴: 계속 추가, 얼굴만 따기, 움직이는 얼굴

**권장 모델**: 쏘넷 · **대상**: 얼굴 관리 화면, 동물 미용실 4단계 · **앞 단계**: P2

## 왜
아이 얼굴, 엄마, 삼촌, 할머니 얼굴이 캐릭터로 나오면 아이가 훨씬 좋아합니다.

## 먼저 읽을 것
`설계/config.json`(`cast`), `index.html`의 `CAST`·`pickPhoto`·사진 자르기(`#cropper`)·친구들 화면(`games.friends`), `salon.js`

## 할 일
1. **얼굴 자리** (`cast.slots`, `cast.unlimited`): 기본 자리는 아기·엄마·아빠·삼촌·할머니. 화면 맨 끝의 **"+ 얼굴 추가"** 로 언제든 더 넣을 수 있고 개수 제한이 없습니다. 추가할 때 부를 이름과 영어 이름을 적습니다. 사진이 많아지므로 저장은 IndexedDB로 옮기고, 기존 데이터는 처음 한 번 옮깁니다(`cast.storage`).
2. **어른용 얼굴 관리 화면**: 어른 확인 뒤 들어감. 자리마다 사진 넣기(찍기 또는 고르기) → **얼굴만 따기**(`cast.faceCut`) → 부를 이름. 지우기.
   - 얼굴만 따기: 타원 틀을 손가락으로 옮기고 크기를 맞춤 → 턱선과 머리카락은 기존 배경 지우기 도구(지우개·되살리기)로 손봄 → 가장자리를 부드럽게. 기기가 얼굴 찾기(`FaceDetector`)를 지원하면 틀을 자동으로 맞추고, 지원하지 않으면 손으로만.
   - 표정 사진(선택): 한 사람에 3장까지(기본·웃는 얼굴·놀란 얼굴).
3. **얼굴 캐릭터 그리기**: `ART.person(photo, opt)`를 `art.js`에 추가. 오려낸 사진 얼굴 + 그린 몸(둥근 어깨와 옷) + 그린 머리 장식 자리. 외곽선과 그림자는 `스타일견본.html` 그림체. 사진이 없는 자리는 쓰지 않습니다.
   - **움직이는 얼굴** (`cast.emoticon`): `ML.Face.play(el, motion)`으로 왼쪽 보기·오른쪽 보기·위아래 끄덕·갸웃·통통·부르르를 만듭니다. 사진을 살짝 기울이고 늘이고 옮겨서 고개를 돌리는 것처럼 보이게 합니다(3D 변환과 한쪽으로 살짝 밀기). 그 위에 그린 효과(볼 빨개짐, 하트, 반짝이, 땀방울, 쿨쿨)를 얹습니다.
   - 표정 사진이 있으면 기쁠 때 웃는 얼굴, 새것이 나올 때 놀란 얼굴로 바꿔 보여 줍니다. 없으면 움직임과 효과만.
   - 움직임은 차분하게: 한 번에 0.6~1초, 계속 반복하지 않음.
4. **미용실 4단계**: 손님으로 가족 얼굴 캐릭터가 옵니다. 사람 손님은 진흙 대신 "머리 감기"로: 거품 → 헹굼 → 말림은 같고, 꾸미기 카드도 같습니다. 인사말은 "할머니가 오셨어요! Grandma is here!"처럼 이름으로.
5. **칭찬에 얼굴**: 한 판이 끝나면 넣어 둔 얼굴 중 하나가 작게 나와 손뼉 치는 장면(3초). 사진이 하나도 없으면 토토가 대신.
6. 사진은 기기에만 저장됨을 관리 화면에 한 줄로 적습니다. 저장 공간이 모자라면 알려 줍니다(기존 방식).

## 바꾸지 말 것
공주 모험의 주인공 사진 기능. 사진 크기 256px.

## 완료 기준
1. 테스트용 그림 파일로 할머니 자리에 사진을 넣고, 미용실 4단계에서 할머니가 손님으로 나오는 것을 확인.
5. "+ 얼굴 추가"로 8번째, 9번째 얼굴을 넣을 수 있고 다시 열어도 남아 있음.
6. 움직임 7가지가 각각 실제로 다른 모습으로 보임(캡처).
2. 사진이 하나도 없어도 4단계가 오류 없이 동물 손님으로 진행.
3. 예전에 저장된 얼굴 데이터가 그대로 보임.
4. `tests/audit.js`, `tests/monkey.js` 통과.

## 끝나고 알려 줄 것
얼굴 캐릭터 캡처, 실제 사진으로 사람이 확인해야 할 것(얼굴 맞추기 편한지).
