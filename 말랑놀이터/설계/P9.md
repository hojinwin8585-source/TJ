# P9. 홈 다시 짜기와 내 방

**권장 모델**: 오퍼스 (그림과 배치) · **앞 단계**: P2 (단계와 선물), P8이 끝나 있으면 가장 좋음

## 왜
지금 홈은 세로로 길고 누를 곳이 12개입니다. 숫자마스터처럼 **가운데 집과 둥근 문 4개, 내 방**으로 한 화면에 다 보이게 하고, 모은 선물로 꾸미는 내 방을 만듭니다.

## 먼저 읽을 것
`설계/config.json`(`home`, `themes`, `calm`), `hub.js`, `벤치마킹.md`의 숫자마스터·BabyBus 수학·Khan Academy Kids 부분

## 할 일
1. **한 화면 홈** (`home.layout`): 세로로 밀지 않습니다. 위에 토토와 큰 시작 버튼(화면 폭의 40% 이상), 가운데 우리 집, 둘레에 둥근 문 4개(각 130px 이상), 아래에 내 방으로 가는 문.
2. **문 4개** (`home.portals`): 요리, 꾸미기, 배움, 노래. 누르면 이름을 한국어·영어로 말하고 들어갑니다. 지금의 직업 마을과 공주 모험은 배움 문 안으로, 친구들과 도장은 내 방 안으로.
3. **문 안** (`home.inside`): 놀이 그림 타일을 한 번에 4개까지. 더 있으면 큰 화살표로 다음 장. 타일은 이모지가 아니라 직접 그린 그림.
4. **시작 버튼**: 오늘의 놀이 3개가 차례로 이어집니다(지금의 오늘의 미션을 사용). 3개가 끝나면 조용한 축하와 선물.
5. **내 방** (`home.mySpace`): 빈 방 그림에서 시작. 단계가 오를 때마다 받은 선물(스티커, 가구, 장식)이 선물 상자로 들어오고, 아이가 상자를 콕 → 방의 **반짝이는 자리**를 콕 하면 놓입니다. 사진으로 넣은 옷은 옷걸이에, 가족 얼굴은 액자에 보입니다. 놓은 것은 저장됩니다.
6. 선물 그림 20개 이상을 `art.js`에 `ART.GIFTS`로 (곰 인형, 화분, 액자, 러그, 전등, 책장, 풍선 등).
7. 크리스마스 테마(P7)가 켜져 있으면 집과 문에도 눈과 전구가 보입니다.
8. 안내 손은 4초 가만히 있으면 시작 버튼을 가리킵니다.

## 바꾸지 말 것
놀이 화면에서 뒤로 가면 그 문 안으로 돌아가는 동작. 어른 설정 들어가는 방법(톱니 2초).

## 완료 기준
1. 390 × 780 화면에서 홈이 스크롤 없이 다 보임.
2. `tests/audit.js`에서 `home`과 문 안 화면이 모두 통과(누를 것 110px 이상, 문 안 타일 4개 이하).
3. 단계가 오르면 선물이 생기고, 내 방에 놓은 뒤 앱을 다시 열어도 그대로 있음.
4. `tests/monkey.js` 오류 0건.

## 끝나고 알려 줄 것
홈·문 안·내 방 캡처, 크리스마스 테마에서의 홈 캡처.
