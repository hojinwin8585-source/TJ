# P2. 동물 미용실 v2: 가게 앞 손님 고르기 · 움직이는 도구 · 자유 꾸미기 · 단계 올리기

**권장 모델**: 오퍼스 (그림과 움직임을 새로 만듦) · **대상**: 동물 미용실(`salon.js`) · **앞 단계**: P1 완료
**두 부분으로 나눠서 합니다**: 먼저 **2-가**를 끝내고 확인받은 뒤 **2-나**.

## 왜 (실제 사용 후기)
P1 뒤 터치는 쉬워졌지만:
- 샤워기·드라이기가 **움직이지 않고 콕콕 누르기만** 해서 단조롭고 지루하다. (다른 앱에서는 샤워기를 움직여 씻기고, 드라이기를 움직이면 바람 효과가 난다.)
- 손님이 바로 와서 **고를 수가 없다**. (가게 앞으로 나갔다가 손님이 오면 골라서 데려오는 흐름이 좋다.)
- 장식을 **떼었다 붙였다 할 수 없고**, 붙이면 바로 끝나서 금방 끝난다.

## 먼저 읽을 것
`설계/config.json`의 `games.petsalon`(`lobby`, `needs`, `tools`, `reactions`, `dressing`, `progressBar`, `levels`, `petStates`), `touch`, `calm`, `sound.dryer`, `sound.shower`, `progress`
코드: `salon.js`(지금 흐름), `play2.js`의 `ML.P2.makeRub`(P1에서 만든 문지르기), `art.js`의 `animal()`, `ART.paper`, `스타일견본.html`(1~7번 그림체)
`config.js`는 `config.json`과 같은 내용입니다(`window.MLCFG`). 값은 코드에 직접 쓰지 말고 여기서 읽으세요.

## 2-가. 가게 앞 · 움직이는 도구 · 자유 꾸미기

### 1. 가게 앞 화면 (`games.petsalon.lobby`)
1. 미용실에 들어오면 먼저 **가게 앞**: 미용실 문, 유리창, 기다리는 의자에 손님 **3마리**. 배경은 외곽선 없는 종이 겹(차분한 색), 동물은 말랑 그림체.
2. 손님마다 머리 위 작은 말풍선에 **원하는 것이 그림으로**(`needs`): 진흙 얼룩, 나뭇잎, 엉킨 털, 리본. 글자 없음. 단계(`from`)보다 높은 요구는 나오지 않음(2-나 전에는 1단계로 취급하지 말고 `muddy`, `leaves`, `party`가 나오게 해도 됨).
3. 손님을 콕 → 이름을 한국어·영어로 부르고("토끼야, 들어와! Come in, bunny!") → 깡충 문 안으로 → 미용실 화면.
4. 미용실 화면의 뒤로 가기는 **가게 앞으로**, 가게 앞의 집 버튼은 홈으로.
5. 손님이 끝나고 나가면 가게 앞에서 그 손님이 문 밖으로 걸어가고, **새 손님이 천천히 걸어와** 빈 의자에 앉습니다(한 번에 한 마리).
6. 가게 벽에 **액자 3개**: 최근에 꾸며 준 손님(장식 데이터로 다시 그림). 저장은 기존 `mallang_salon`에.

### 2. 손가락을 따라 움직이는 도구 (`games.petsalon.tools`)
1. 거품(수세미)·헹굼(샤워기)·말림(드라이기) **세 단계 모두** 같은 방식: 동물 아무 데나 손가락을 대면 도구가 **손가락 위쪽**(`offsetAboveFingerRatio`)에 붙어서 따라다님. 도구를 따로 집을 필요 없음. 크기는 `touch.tool`.
2. **효과가 닿는 자리만 바뀜** (`coverage`): 동물 그림 안을 6×6 칸으로 나누고, 효과 반지름 안의 칸이 처리됨. 진행 = 처리된 칸 비율. `doneAt`(85%)이 되면 나머지는 반짝이며 저절로 끝.
   - 가만히 대고만 있어도(`holdStillCleansNearest`) 가까운 칸부터 천천히 처리되어 **결국 끝남**(P1의 `holdProgressPerSec` 속도). 진행은 줄지 않음.
   - P1의 `makeRub`를 고쳐 쓰거나, 칸 방식으로 `ML.P2.makeTool(el, opts)`를 새로 만들어 세 도구가 함께 씀.
3. **샤워기**: 샤워기 머리에서 손가락 지점까지 물줄기(연한 하늘색 물방울이 떨어지는 애니메이션). 물이 닿은 칸의 거품과 진흙만 지워짐(지워지는 모습이 보이게: 그 자리 거품이 퐁퐁 사라짐). 소리는 대고 있는 동안만, 150ms에 걸쳐 켜지고 꺼짐.
4. **드라이기**: 입에서 손가락 지점까지 부드러운 바람 줄 3개. 바람이 닿은 칸의 물방울이 날아가고, 그 자리 털이 **보송하게 부풀어 오름**(털 뭉치 그림). 귀가 살랑. 소리는 대고 있는 동안만, `sound.dryer.volumeByUse`대로 작게 시작. P1의 예고 음성과 어른 설정 그대로.
5. **동물 반응** (`reactions`, 한 손님에 각각 최대 1번): 배를 문지르면 키득, 코에 거품이 닿으면 작게 "에취!", 헹굼이 끝나면 부르르 털어 물방울 튐, 꾸미는 중에 가끔 거울 보며 웃음.
6. 단계 흐름은 손님의 요구(`needs[].steps`)대로. `party` 손님은 씻기지 않고 바로 꾸미기.
7. 진행 막대는 **빗금 없는 단색**(`progressBar`).

### 3. 자유 꾸미기 (`games.petsalon.dressing`)
1. 씻기가 끝나면 꾸미기. 처음엔 머리·목·얼굴 자리에 은은한 반짝이(움직이지 않음).
2. **동물의 머리·목·얼굴을 콕** → 그 자리 장식 카드 3장이 아래에 나옴. 같은 자리를 다시 콕 하면 다른 3장. (한 화면 선택지 3개 규칙 유지)
3. **붙이기**: 카드를 콕 하거나 동물에게 끌어다 놓기 → 날아가 붙고 또렷한 색으로 피어남.
4. **바꾸기**: 같은 자리에 다른 카드 → 원래 것은 카드 쪽으로 날아 돌아가고 새것이 붙음.
5. **떼기**: 동물에 붙은 장식을 **끌어서 밖으로** 빼면 떨어짐("퐁", 카드 쪽으로 돌아감).
6. **색 바꾸기**: 붙은 장식을 **콕** → 다음 색으로 바뀌고 색 이름을 한국어·영어로("노랑! Yellow!").
7. **끝내기는 아이가**: 장식이 1개 이상 붙고 8초가 지나면 오른쪽 아래에 큰 **거울 버튼**이 조용히 나타남. 누를 때만 끝남. 30초 동안 가만히 있으면 안내 손이 거울을 가리킴(자동으로 끝나지 않음).
8. **거울 장면**: 동물이 거울 앞에서 빙글 돌고 웃음 → 부드러운 찰칵 → 액자가 되어 가게 벽으로 → "고마워! Thank you!" 손 흔들며 문 밖으로 → 가게 앞.

### 바꾸지 말 것 (2-가)
P1의 색 규칙(고를 땐 차분, 결과는 또렷), 소리 규칙(누를 때만, 작게 시작), 엉뚱한 곳 응원, 카드 110px 이상, 한 화면 선택지 3개. 다른 놀이.

### 완료 기준 (2-가)
`tests/salon.js`를 새 흐름에 맞게 고치고, `tests/p2a.js`를 새로 만들어:
1. 미용실에 들어가면 가게 앞에 손님 3마리, 그중 하나를 콕 하면 그 손님이 미용실에 들어옴(고른 동물 종류가 같은지).
2. 샤워 단계에서 손가락을 **동물의 왼쪽 위에서만** 움직이면 그 칸들만 지워지고 오른쪽 아래 칸은 남아 있음(칸 상태 확인). 계속하면 85%에서 끝남.
3. 샤워기와 드라이기 그림이 손가락을 따라 움직임(손가락 이동 전후 도구 위치가 달라짐), 물줄기·바람 요소가 대고 있을 때만 보임.
4. 가만히 대고만 있어도 각 씻기 단계가 20초 안에 끝남.
5. 장식 붙이기 → 같은 자리 바꾸기 → 끌어서 떼기 → 다시 붙이기 → 콕으로 색 바꾸기가 모두 되고, 거울 버튼을 누르기 전에는 끝나지 않음(장식 붙이고 40초 기다려도 꾸미기 단계 그대로).
6. 거울을 누르면 가게 앞으로 돌아오고 벽 액자가 1개 늘어남.
7. `tests/p1.js`, `tests/audit.js`의 `petsalon`, `tests/monkey.js` 통과.

가게 앞, 샤워(물줄기), 드라이(바람과 부푼 털), 꾸미기(떼기 전후), 거울 장면 캡처. 실제 기기에서 확인할 것.

## 2-나. 변하는 모습 6가지 + 별 3칸으로 단계 올라가기 (2-가 확인 뒤)
1. **동물의 모습** (`petStates`): `ART.animal(kind, mood, opt)`에 `opt.state`와 칸별 상태를 받아 그립니다. 진흙 → 거품 → 젖음(털이 처지고 물방울) → 보송(털 풍성, 은은한 윤기). 2-가의 칸 방식과 맞물려 **닿은 자리부터** 바뀝니다. 네 동물 모두.
2. **단계 엔진** `ML.Progress`(새 파일 `progress.js`): `get(gameId)` → `{level, clears}`, `clear(gameId)` → 별 1칸, 3칸이면 `level+1`. `struggle(gameId)`는 `progress.struggle` 기준, 두 번 연속이면 조용히 한 단계 내림. 저장은 `progress.storageKey`. 어른 설정에서 놀이별 단계를 고를 수 있게.
3. **별 3칸**: 미용실 화면 위쪽. 손님 한 명이 끝나면(거울 장면 뒤) 한 칸이 천천히 채워짐.
4. **단계 오르는 순간** (`progress.levelUpMoment`): 새로 생긴 것 하나를 크게 보여 주고 이름을 한국어·영어로. 3초 안에 끝.
5. **단계표** (`levels` 1~3): 손님 종류, 요구(`needs[].from`), 씻기 단계, 꾸밀 자리, 카드에 나오는 장식 수, 색 수가 단계에 따라 달라짐. 3단계부터 빗(`tools.brush`)과 엉킨 털 손님. (4·5단계는 P4, P6에서)
6. 새 단계가 열리면 `document.dispatchEvent(new CustomEvent('ml-levelup', {detail:{game, level}}))`.

### 완료 기준 (2-나)
1. 1단계에서 3명 → 2단계로 오르고 드라이 단계와 목 장식이 생김.
2. 칸별로 그림이 실제로 달라짐(상태 이름과 캡처).
3. 어른 설정에서 단계를 1로 되돌릴 수 있음.
4. `tests/p2a.js`, `tests/p1.js`, `tests/audit.js`, `tests/monkey.js` 통과.

### 끝나고 알려 줄 것 (2-나)
모습별 캡처, 단계표가 `config.js` 값대로 움직이는지.
