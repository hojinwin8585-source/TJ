# P2. 변하는 모습 6단계 + 별 3칸으로 단계 올라가기

**권장 모델**: 오퍼스 (그림을 새로 그림) · **대상**: 동물 미용실 · **앞 단계**: P1 완료

## 왜
씻기고 말릴 때 변화가 단계별로 보여야 하고, 같은 단계를 3번 하면 다음 단계로 올라가야 합니다.

## 먼저 읽을 것
`설계/config.json`(`progress`, `games.petsalon`), `salon.js`, `art.js`의 `animal()`, `스타일견본.html`

## 할 일
1. **동물의 모습 6가지** (`games.petsalon.petStates`): `ART.animal(kind, mood, opt)`에 `opt.state`를 추가해 그립니다.
   - `muddy`: 진흙 얼룩, 풀이 죽은 표정
   - `foamy`: 문지른 자리부터 거품 (손가락 위치 기준)
   - `rinse1`~: 누를 때마다 거품이 위에서부터 3분의 1씩 사라짐
   - `wet`: 털이 축 처지고 귀가 내려가고 물방울
   - `dry1`~: 누를 때마다 머리 → 몸 순서로 보송해짐
   - `fluffy`: 털이 풍성하고 은은한 윤기, 활짝 웃음
   네 동물 모두 같은 규칙으로. 누를 때마다 숫자를 말해 줍니다 ("하나! One!").
2. **단계 엔진** `ML.Progress` (새 파일 `progress.js`):
   - `get(gameId)` → `{level, clears}` / `clear(gameId)` → 별 1칸, 3칸이면 `level+1`
   - `struggle(gameId)` → `progress.struggle` 기준으로 두 번 연속이면 조용히 한 단계 내림
   - 저장은 `progress.storageKey`. 어른 설정에서 놀이별 단계를 직접 고를 수 있게.
3. **별 3칸 표시**: 놀이 화면 위쪽에 별 3칸. 한 판 끝나면 한 칸이 천천히 채워집니다.
4. **단계 오르는 순간**: 3칸이 차면 `progress.levelUpMoment`대로, 새로 생긴 것 하나를 크게 보여 주고 이름을 한국어·영어로 말합니다. 3초 안에 끝.
5. **미용실 단계표 적용** (`games.petsalon.levels` 1~3단계): 손님 종류, 씻기기 장면, 고르기 종류, 카드 수, 색 수가 단계에 따라 달라집니다. (4·5단계는 P4, P6에서)
6. 새 단계가 열리면 `document.dispatchEvent(new CustomEvent('ml-levelup', {detail:{game, level}}))`를 보냅니다 (P6에서 씀).

## 바꾸지 말 것
P1의 문지르기, 소리, 색. 카드 크기(110px 이상).

## 완료 기준
1. `tests/salon.js`를 고쳐서: 1단계에서 3판 → 2단계로 올라가고 드라이 단계가 생기는지 확인.
2. 헹굼과 말림에서 누를 때마다 그림이 실제로 달라지는지(상태 이름 또는 캡처) 확인.
3. 어른 설정에서 단계를 1로 되돌릴 수 있음.
4. `tests/audit.js`, `tests/monkey.js` 통과.

## 끝나고 알려 줄 것
상태별 캡처 6장, 단계표가 `config.js` 값대로 움직이는지.
