# P12. 살아 있는 캐릭터 · 큼직한 도구 · 가게 놀이의 진행 뼈대

**권장 모델**: 오퍼스 (캐릭터 그림을 움직이게 다시 묶음) · **대상**: `art.js`의 `animal()`, 새 파일 `alive.js`, `salon.js`, `nailshop.js` · **앞 단계**: P2-가, P11
**두 부분으로**: 먼저 **12-가**(캐릭터와 도구), 확인 뒤 **12-나**(진행 뼈대와 새 과정)

## 왜 (실제 사용 후기와 검토)
"최소한 다른 유아 역할놀이 앱처럼 진행되게, 캐릭터들이 더 많이 움직였으면, 도구는 큼직하게."
검토 결과:
- P1에서 자극을 줄이려고 "반복 움직임은 안내 손과 대상 하나만"으로 정한 탓에, 지금 미용실과 네일숍의 캐릭터는 **반응할 때 말고는 완전히 멈춰 있습니다**(반복 움직임 0개, 눈 깜빡임도 꺼짐). 차분함은 색과 효과로 지키고, 캐릭터는 느리고 작게 **끊임없이** 움직이게 규칙을 바꿉니다(`calm.characterLife`).
- 도구가 휴대폰에서 130px(무대 폭의 32%)이라 작습니다. 45%, 최소 180px로 키웁니다(`touch.tool`).
- 한 판의 흐름에 이음 장면과 보상이 없어 뚝뚝 끊깁니다(`flow`).

## 먼저 읽을 것
`설계/config.json`의 `calm.characterLife`, `touch.tool`, `flow`, `games.petsalon`, `games.nailshop`
코드: `art.js`의 `animal()`(지금 구조), `salon.js`, `nailshop.js`, `play2.js`의 `makeTool`, `스타일견본.html`

## 12-가. 살아 있는 캐릭터와 큼직한 도구

### 1. 캐릭터 몸을 움직일 수 있게 묶기 (`characterLife.engine`)
`ART.animal(kind, mood, opt)`의 그림을 몸·머리·귀(좌우)·꼬리·눈·눈꺼풀·눈동자·팔(좌우)·입으로 `<g class>`를 나눠 묶습니다. 네 동물 모두, 겉모습은 지금과 같게(기존 화면이 깨지지 않게, 기존 `mood` 그대로 동작).

### 2. `alive.js` — `ML.Alive.attach(el, {kind})`
- **늘 하는 움직임** (`idle`): 숨쉬기, 깜빡임, 귀·꼬리 살랑, 머리 갸웃, 둘러보기. 주기와 크기는 config 값. 한 캐릭터 안에서 주기가 서로 달라 기계처럼 보이지 않게.
- **손가락 따라보기** (`followFinger`): 화면에 손가락이 닿아 있으면 눈동자와 머리가 그쪽을 살짝.
- **표정** `setMood(name)`: 시무룩·간질간질·부르르·활짝 등, 0.3초에 걸쳐 바뀜(`moods`).
- **도구를 쓰는 동안** `setTool(name|null)`: `whileTool`의 반응을 대고 있는 동안 계속.
- **큰 동작** `play(name)`: hop, clap, twirl, dance, wave, shiver, peekMirror. 한 번에 하나만.
- **짧은 소리** (`voiceSounds`): 키득, 아~, 히히, 우와. WebAudio.
- `limits`를 지킴(가장 빠른 주기 0.6초, 회전 8도, 이동 14px 이하, 번쩍임 없음). `detach()`와 화면을 떠날 때 모든 타이머 정지. `prefers-reduced-motion`이면 숨쉬기와 깜빡임만.

### 3. 미용실과 네일숍에 붙이기
- 미용실: 손님(욕조 안, 꾸미기), **가게 앞에서 기다리는 손님 3마리**(`waiting`: 다리 흔들기, 차례로 손 흔들기), 벽 액자 속 그림은 멈춤.
- 미용실 과정마다 `whileTool`과 `bigMoments`(들어올 때 깡충, 과정 끝 폴짝+박수, 새 장식에 거울 보고 빙글, 떼면 '어?', 끝나면 춤).
- 네일숍: 손님 얼굴이 손톱을 내려다보고 반응, 칠할 때 손가락 꼼지락, 기다릴 때 손가락을 톡톡, 토토 발은 젤리가 말랑. 램프 안을 들여다봄.
- P2-가의 반응(키득·에취·부르르)은 `Alive`로 옮기되 "한 손님에 1번" 제한은 에취만 남기고, 키득과 표정 반응은 계속.

### 4. 큼직한 도구 (`touch.tool`)
- 미용실 도구: 무대 폭 45%, 최소 180px, 최대 300px. 네일숍 도구: `nailToolRatio`.
- 도구 칸의 도구 그림 150px 이상. 과정이 시작되면 도구가 도구 칸에서 **통통 튀어 올라와** 이름을 말함(`intro`).
- 도구에 작은 얼굴, 쓰는 동안 깜빡이고 신난 표정(`face`).
- 도구가 커져도 손가락 아래 효과 지점은 그대로(가리지 않게 손가락 위쪽 유지), 캐릭터 얼굴을 다 가리지 않게 도구가 얼굴 위에 오면 60% 투명도.

### 완료 기준 (12-가)
`tests/p12a.js`(새로):
1. 미용실 손님과 가게 앞 손님, 네일숍 손님에서 2초 간격으로 두 번 잰 몸·눈·귀의 변형 값이 서로 다름(가만히 있지 않음). 8초 안에 깜빡임이 1번 이상.
2. 손가락을 왼쪽에 대면 눈동자가 왼쪽, 오른쪽에 대면 오른쪽으로 옮겨감.
3. 샤워 중과 드라이 중의 표정·자세 상태가 서로 다르고, 손을 떼면 기본으로 돌아옴.
4. 과정이 끝날 때 큰 동작(hop 또는 clap)이 기록됨. 큰 동작이 동시에 두 개 돌지 않음.
5. 도구 폭이 390px 화면에서 175px 이상, 도구 칸 그림 150px 이상.
6. 어떤 움직임도 주기 0.6초 미만이 아님(선언된 animation-duration 검사), 화면을 떠나면 타이머 0개.
7. `tests/p2a.js`, `tests/salon.js`, `tests/nailshop.js`, `tests/p1.js`(움직이는 것 개수 검사는 캐릭터를 빼고 세도록 고침), `tests/audit.js`의 두 화면, `tests/monkey.js` 통과.

### 끝나고 알려 줄 것 (12-가)
움직임을 보여 주는 연속 캡처(같은 장면 4장씩: 기다림, 샤워 중, 드라이 중, 춤), 도구 크기 전후, 오래된 기기에서 버벅일 수 있는 부분.

## 12-나. 진행 뼈대와 새 과정 (12-가 확인 뒤)
1. **과정 그림 줄** (`flow.stepStrip`): 화면 위에 이번 손님의 과정 2~4개, 지금 과정만 크게.
2. **이음 장면** (`flow.beats` 4번): 욕조에 퐁당, 수건으로 감쌌다 풀기, 의자 빙글 등 1.5초.
3. **새 과정** (`flow.extraSteps`): 나뭇잎 콕콕 떼기, 수건 톡톡, 향수 칙. `games.petsalon.needs`의 순서에 끼움.
4. **보상** (`flow.reward`): 손님이 나가며 하트 1개 → 화면 위 바구니. 저장.
5. 네일숍에도 같은 뼈대(과정 그림 줄, 이음 장면: 손을 쓱 내밀기·램프로 쏙, 보상).
