# P5. 색칠 놀이(새로) + 요리 단계

**권장 모델**: 오퍼스 (새 놀이와 그림) · **앞 단계**: P1, P2 · **두 부분으로 나눠서 해도 됨** (5-가 색칠, 5-나 요리)

## 왜
색칠과 요리도 "같은 단계 3번 → 다음 단계"로 재료와 색이 늘어나야 합니다.

## 먼저 읽을 것
`설계/config.json`(`games.coloring`, `games.pizza`, `calm.choiceColors`), `salon.js`(본보기), `pizzashop.js`, `개선명세.md` 4-4, `progress.js`

## 5-가. 색칠 놀이 (`coloring.js`, 화면 id `coloring`, 꾸미기 살롱 건물에 넣기)
1. 화면: 가운데 큰 그림(굵은 갈색 선, 칸이 큼), 아래에 **물감 카드**(최대 3장이 한 번에 보임, 110px 이상).
2. 흐름: 토토가 "무슨 색으로 칠할까?" → 물감 카드 하나 콕 → 색 이름을 한국어·영어로 → 그림에서 **반짝이는 칸**을 콕 → 그 칸이 부드럽게 채워짐(0.8초) → "예쁘다! Beautiful!" → 다음 칸.
3. 단계 (`games.coloring.levels`):
   - 1단계: 칸 1개, 색 2개 (사과, 풍선)
   - 2단계: 칸 3개, 색 3개
   - 3단계: 칸 5개, 색 5개. 콕 대신 쓱쓱으로도 채워짐(P1의 `makeRub`)
   - 4단계: 칸 8개, 색 8개, 무늬 도장. 가족 얼굴 그림 포함(P4가 있으면)
   색이 3개를 넘으면 물감 카드가 한 번에 3장씩 차례로 바뀝니다(가로로 밀지 않음).
4. 칸은 어디를 눌러도 인정되도록 넉넉하게. 칸 밖을 누르면 응원.
   - 색 규칙(`calm.colorPolicy`): 물감 카드와 빈 그림은 차분한 색, **칠해진 칸만 또렷한 색**으로 0.6초 동안 피어납니다.
5. 다 칠하면 그림이 살짝 움직이고(풍선이 떠오름 등) 조용한 축하, 별 1칸.
6. 그림은 `art.js`에 `ART.COLORING`으로. 단계마다 그림 2~3장을 돌아가며.

## 5-나. 피자가게 고치기 (사용 후기에서 나온 잘못)
**먼저 읽을 것**: `config.json`의 `rules`(전부), `flow`, `touch.tool`, `calm.characterLife`, `games.pizza`
잘못된 점(`rules.found`): 5번 썰면 10조각이 보이는데 4조각만 올리면 넘어감 · 옥수수는 준비 과정 없이 작은 덩어리로 올라감 · 글자 안내 줄(`hint`)이 17곳 · 점선 따라 긋기.
1. **만든 만큼 쓰기** (`rules.madeEqualsUsed`): 한 재료를 4번 썰면 도마 옆 접시에 **4조각이 그대로** 놓임. 올리기에서는 접시의 조각을 콕 하면(또는 끌면) 피자로 날아가고, **접시가 빌 때까지** 다음으로 넘어가지 않음. 남은 조각이 항상 보임.
2. **모든 재료에 준비 과정** (`rules.everyIngredientPrepared`): 통째 그림에서 시작. 옥수수는 자루를 쓱쓱 문질러 알 떼기, 올리브는 병에서 톡톡, 치즈는 강판에 쓱쓱(모두 `ML.P2.makeTool`). 피자 위 조각은 피자 지름의 16% 이상.
3. **글자 없이** (`rules.noReading`, `rules.doNotPressToSkip`): `hint()` 글 안내 줄을 모두 없애고 안내 손과 음성으로. '다음' 버튼 없이 과정이 끝나면 이음 장면 뒤 저절로 다음으로.
4. **조작**: 가루와 물은 콕 하면 한 컵씩. 피자 자르기는 점선 긋기 대신 **피자 칼 도구를 움직여** 지나간 선이 잘림(굵은 길, 근처만 가도 인정, `touch.trace`). 길게 누르기(`makePour`) 삭제. 도구는 `touch.tool` 크기.
5. **같은 배치** (`rules.sameLayoutEverywhere`): 위 과정 그림 줄, 가운데 무대, 아래 도구 칸.
6. **손님이 살아 있게**: P12-가의 `ML.Alive`를 손님에게 붙임(기다리며 배를 문지름, 토핑을 올릴 때마다 눈이 커짐, 다 되면 냠냠과 춤).
7. 단계 (`games.pizza.levels`): 1단계는 소스·토마토 썰기·올리기·굽기. 단계가 오르면 반죽, 치즈 갈기, 재료 2가지, 재료 고르기(카드 3장), 피자 자르기, 손님 주문이 차례로. `ML.Progress`가 없으면 1단계 고정 + 어른 설정에서 바꾸기.
8. **`tests/rules.js`를 새로 만들기**: `rules.*.test`를 자동 검사(글자만 있는 버튼, 그림 비율, 세 구역 배치, 조각 수 일치). 우선 `pizza`, `petsalon`, `nailshop`에 돌리고, 다른 화면은 목록만 출력(P8에서 고침).

## 바꾸지 말 것
P1의 색·소리·문지르기 규칙. 한 화면 선택지 3개 이하.

## 완료 기준
1. 새 테스트 `tests/coloring.js`: 1단계 3판 → 2단계에서 칸 3개와 색 3개가 나오는지.
2. `tests/pizza.js`(새로): 콕과 쓱쓱만으로 1단계 완주. 썬 조각 수 == 접시의 조각 수 == 끝났을 때 피자 위의 수이고, 접시에 조각이 남아 있으면 다음으로 넘어가지 않음. 옥수수가 문지르기 과정을 거침. 화면에 글자 안내 줄과 글자 버튼이 없음.
4. `tests/rules.js`에서 `pizza`, `petsalon`, `nailshop` 통과.
3. `tests/audit.js`에서 `coloring`, `pizza` 통과. `tests/monkey.js` 통과.
