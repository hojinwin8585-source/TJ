# 벤치마킹: 다른 앱에서 배울 것

확장 웹검색으로 조사했습니다. 앱스토어 소개글, 기사, 리뷰, 연구 자료를 바탕으로 했고, **직접 앱을 실행해 본 것은 아닙니다.**

## 1. 앱별로 가져올 점

| 앱 | 좋은 점 | 말랑 놀이터에 적용 | 단계 |
|---|---|---|---|
| **Pok Pok** | 손으로 그린 그림과 부드러운 소리로 **자극을 줄임**. 이기고 지는 것이 없고 조용함. 여러 번 들어도 피곤하지 않은 소리 | 채도 낮은 색, 무늬 없는 배경, 조용한 축하, 부드러운 소리 | P1 |
| **Khan Academy Kids** | 큰 ▶ 하나로 놀이가 차례로 이어짐. 하루 5~20분 뒤 기기를 내려놓게 권함. 캐릭터가 안내 | 오늘의 놀이 3개, 10분 약속 | P3 |
| **핑크퐁 123 숫자놀이** | **이름 배우기 → 세어 보기 → 따라 쓰기** 3단계 | 한 주제를 3단계로 올리기 (보기 → 해 보기 → 스스로) | P2, P5 |
| **Noggin** | 캐릭터가 먼저 **시범**을 보이고 아이가 따라 함 | 안내 손 시범 (이미 있음), 토토가 먼저 해 보이기 | P1 |
| **Lingokids** | 2~8세, 아이 속도에 맞춰 조정, 광고 없음 | 어려워하면 조용히 한 단계 내리기 | P2 |
| **베베핀 타운** | 주인공과 공간을 돌아다님, 양치·목욕·정리 같은 생활 놀이, 감정 고르기 | 가족 얼굴이 손님으로, 씻기기 놀이 | P4 |
| **Babybus** | 동물 손님을 씻기고 꾸미기, 글 없이 그림과 말 | 동물 미용실 (완성) | 완료 |
| **차이의 놀이** | 월령에 맞는 **화면 밖 놀이**를 부모에게 추천 | 놀이가 끝나면 "진짜 수건으로 인형 말려 주기" 같은 제안 | P3 |
| **토도 (에누마)** | 오늘 할 분량을 정해 보여 줌, 부모 리포트 | 오늘의 놀이, 어른 화면에 기록 | 완료/P3 |
| **웅진 스마트올 키즈** | 하루 20분 놀이형, 동화·동요·놀이로 개념, 혼자서도 쓰게 한 화면 | 동요 배경음, 짧은 하루 분량 | P1, P3 |

## 2. 연구와 지침에서 가져올 점

| 주제 | 내용 | 적용 |
|---|---|---|
| 빠른 화면 | 4세 60명 실험에서, 빠르게 바뀌는 만화를 9분 본 직후 자기 조절 과제 점수가 낮았음 (Lillard & Peterson, 2011). 표본이 작고 직후 효과만 봄 | 장면 전환을 4초 이상 간격으로, 움직이는 것 2개까지 |
| 무서운 소리 | NHS 자료: **미리 알려 주기, 아이가 직접 켜고 끄기, 아주 작은 소리부터 조금씩**, 우스운 모습으로 꾸미기 | 드라이기 친구, 예고 음성, 눌러야만 켜짐, 소리를 4단계로 키움 |
| 시간 제한 | Apple 지침: 시간이 끝나면 차단만 하지 말고 다른 경험으로 넘기기. 어른 확인은 **어른만 풀 수 있는 과제**로 | 조용한 쉬는 화면, 말로 불러 준 숫자 누르기 |
| 단계 올리기 | 숙달 기준은 고정하고 걸리는 시간은 아이마다 다르게. 숙달은 영구적이지 않으니 다시 확인 | 별 3칸, 어려워하면 내려가기 |
| 터치 | 유아는 누르기·끌기는 잘하고 길게 누르기·두 번 누르기가 가장 어려움. 움직이는 손 시범이 도움 | 콕과 쓱쓱만, 안내 손 |
| 화면 시간 | WHO: 2~4세 하루 1시간 이하 | 10분 × 최대 4번 |

## 3. 확인하지 못한 것 (알려 주시면 반영)
- **웅진의 2~4세 앱**: 검색으로는 스마트올 키즈(4~6세)만 확인됐고, 공식 안내는 "3세 이하는 웅진씽크빅·웅진북클럽 이용"입니다. 마음에 드신 앱의 **정확한 이름이나 화면 캡처**를 주시면 그 구성을 따로 분석하겠습니다.
- **숫자마스터**: 같은 이름의 앱을 찾지 못했습니다. 스토어 링크나 개발사 이름을 알려 주세요. 말씀하신 "같은 단계 3번 → 다음 단계" 방식은 이미 `config.json`의 `progress`에 넣었습니다.
- **아이챌린지 호비**, **Pok Pok 실제 화면 구성**: 자료가 부족했습니다.
