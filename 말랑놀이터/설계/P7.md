# P7. 크리스마스: 캐럴, 홈 테마, 집 꾸미기

**권장 모델**: 오퍼스 (그림을 새로 그림) · **앞 단계**: P1 (배경음 묶음), P2 (단계 엔진) · **12월 전에 끝내기**

## 왜
크리스마스 철에 맞춰 캐럴이 흐르고, 홈이 크리스마스 마을이 되고, 집을 꾸미는 놀이가 하나 생깁니다.

## 먼저 읽을 것
`설계/config.json`(`sound.bgm.sets.christmas`, `themes.christmas`, `games.xmasHouse`, `calm`), `hub.js`, `salon.js`(본보기), `스타일견본.html`

## 할 일
### 7-가. 캐럴과 테마 고르기
1. 어른 설정의 "배경음"에 동요 / 크리스마스 / 끔. 값은 `sound.bgm.selected`에 해당.
2. 크리스마스를 고르면 `sets.christmas.songs`의 가락을 오르골과 작은 종소리로 연주합니다. `sound.bgm.neverUse`의 노래는 넣지 않습니다.
3. `themes.christmas.suggestBetween` 기간에 어른 설정을 열면 한 번만 "크리스마스 배경음으로 바꿀까요?"를 권합니다. 자동으로 바꾸지 않습니다.

### 7-나. 크리스마스 홈
1. 배경음이 크리스마스이면 홈이 `themes.christmas.home`대로 바뀝니다: 지붕과 나무 위의 눈, 집 옆 작은 트리, 처마의 꼬마전구, 토토의 빨간 목도리, 눈송이.
2. **차분함 규칙을 지킵니다**: 눈송이는 최대 10개가 천천히, 전구는 깜빡이지 않고 은은하게 밝아졌다 어두워짐(4초 이상 주기), 색은 `themes.christmas.palette`.
3. 홈에 들어오면 토토가 `themes.christmas.voice`를 말합니다(1분에 한 번 이내).
4. 테마는 CSS 변수와 그림 조각을 바꾸는 방식으로. 놀이 화면의 동작은 바꾸지 않습니다.

### 7-다. 크리스마스 집 꾸미기 (새 놀이 `xmas.js`, 화면 id `xmashouse`)
1. 장면: 차분한 거실. 가운데 큰 초록 트리, 옆에 벽난로와 창문. 꾸미기 문 안에 넣고, 크리스마스 테마일 때는 홈에도 보이게.
2. 단계 (`games.xmasHouse.levels`):
   - 1단계: 방울 카드 2장 중 하나 콕 → 트리의 **반짝이는 자리**를 콕 → 방울이 달림. 3번.
   - 2단계: 꼭대기 별 달기, 그리고 트리를 콕 할 때마다 꼬마전구가 한 줄씩 켜짐(3줄).
   - 3단계: 벽난로에 양말 걸기(카드 3장), 트리 아래 선물 놓기.
   - 4단계: 문에 리스, 창문에 눈, 액자에 가족 얼굴(P4가 있으면), 사진으로 넣은 우리 집 장식(P6이 있으면).
3. 색 규칙: 카드와 배경은 차분하게, **달린 장식만 또렷하게**(`calm.colorPolicy`).
4. 고르면 "빨강 방울! Red ornament!"처럼 말합니다. 다 꾸미면 방 불이 살짝 어두워지고 트리가 은은하게 빛나며 "메리 크리스마스! Merry Christmas!", 별 1칸.
5. 꾸민 트리는 저장해서 다음에 열면 그대로 보입니다. "새로 꾸미기"는 큰 버튼 하나.
6. 그림은 `art.js`에 `ART.XMAS`로: 트리, 방울(색 바꿈), 별, 전구 줄, 양말, 선물 상자, 리스, 벽난로, 눈 쌓인 창문.

## 바꾸지 말 것
P1의 색·소리·문지르기 규칙, 카드 크기(110px 이상), 한 화면 선택지 3개 이하.

## 완료 기준
1. 새 테스트 `tests/xmas.js`: 1단계를 콕만으로 완주, 3판 뒤 2단계에서 별과 전구가 나오는지.
2. 배경음을 크리스마스로 바꾸면 홈에 눈과 트리가 보이고, 동요로 바꾸면 원래대로.
3. 홈에서 동시에 움직이는 것이 눈송이를 빼고 2개 이하, 깜빡이는 것이 없음.
4. `tests/audit.js`에서 `xmashouse` 통과, `tests/monkey.js` 오류 0건.

## 끝나고 알려 줄 것
크리스마스 홈과 단계별 캡처, 캐럴 가락이 맞게 들리는지 사람이 확인할 것.
