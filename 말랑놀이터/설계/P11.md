# P11. 진짜 네일숍: 갈기 · 젤 칠하기 · 램프에 굽기 · 그림 · 파츠

**권장 모델**: 오퍼스 (새 놀이와 그림) · **대상**: 새 파일 `nailshop.js` (화면 id `nailshop`) · **앞 단계**: P2-가(움직이는 도구 `ML.P2.makeTool`, 가게 앞, 떼었다 붙이기를 그대로 다시 씀), 2-나가 끝났으면 단계 엔진 `ML.Progress`도 씀

## 왜 (요청)
"네일도 색칠을 할 수 있게, 네일아트 하는 것처럼 젤도 바르고 모양도 그리고 액세서리도 넣고, 젤 말리는 도구에 굽는 것도, 손톱도 갈아 주고, 실제 네일 하는 것처럼."
지금의 손톱 놀이(`play2.js`의 `nails`)는 손톱을 콕 하면 색이 바로 바뀌는 것뿐입니다.

## 먼저 읽을 것
`설계/config.json`의 `games.nailshop`(전부), `games.petsalon`(`lobby`, `tools`, `dressing`, `itemUnlock`), `calm`, `touch`, `progress`
코드: `salon.js`(P2-가 이후 본보기: 가게 앞, makeTool, 꾸미기 끌어서 떼기, 거울), `play2.js`의 `ML.P2.makeTool`, `art.js`, `스타일견본.html`

## 할 일
1. **새 놀이 `nailshop.js`**: `salon.js`와 같은 방식으로 화면을 등록. 홈 타일 '손톱'(`index.html`의 `data-go="nails"`)을 `nailshop`으로 연결. 예전 `nails` 코드는 지우지 않음. `index.html`에 `<script src="nailshop.js">`, `sw.js` 목록에 추가.
2. **가게 앞** (`lobby`): 손님 3명, 말풍선에 원하는 색 물방울. 손님 콕 → 손님 의자로 → 손이 테이블 위에 놓임. 다른 색을 칠해도 기뻐함.
3. **그림 새로 그리기** (`art.js`에 `ART.HAND`, 말랑 그림체): 엄마 손, 아기 손, 토토 발(발바닥 젤리, 둥근 발톱). 손톱마다 상태(`view.nailState`)를 받아 그림: 울퉁불퉁한 끝 ↔ 매끈한 끝, 베이스(촉촉), 색(칸별로 칠해진 곳만), 윤기(굽기 뒤), 아주 반짝(탑젤 뒤), 그림·도장·파츠. 도구: 손톱 줄, 젤 붓, 색 병, 젤 램프(웃는 얼굴, 둥근 지붕), 스포이트.
4. **과정** (`steps`, `levels`): 단계표의 `steps` 순서대로. 각 과정은 `steps.*.how` 그대로.
   - 갈기·베이스·색·탑젤·오일은 `ML.P2.makeTool` 칸 방식으로 **닿은 곳만** 바뀌고, 가만히 대고 있어도 끝남. 손톱 모양 밖은 바뀌지 않음.
   - 색 젤: 칠한 결이 0.5초 뒤 매끈하게 퍼지는 모습. 손톱을 콕만 해도 붓이 천천히 알아서 칠함.
   - 굽기: 큰 램프 버튼 → 손이 램프 안으로 → 서서히 켜지는 연보라빛 → 5까지 천천히 세기(점 5개) → 띵 → 윤기.
   - 손톱 3개 이상 하면 다음 과정 버튼이 조용히 나타남(5개 다 안 해도 됨).
5. **확대** (`view.zoom`): 그림·도장·파츠에서는 손톱을 콕 하면 그 손톱이 무대를 가득 채움. 손 그림 버튼으로 돌아감.
6. **꾸미기는 자유롭게**: 굽기 뒤 도구 칸에 붓·도장·보석 버튼 3개. 파츠는 동물 미용실과 같은 규칙(콕 또는 끌어 붙이기, 끌어서 떼기, 콕 하면 색 바꾸기).
7. **끝내기는 아이가**: 거울 버튼 → 손님이 손을 들어 보며 기뻐함 → 찰칵 → 손톱 액자가 가게 벽으로 → 가게 앞.
8. **단계** (`levels`): `ML.Progress`가 있으면 3명마다 단계 오름(없으면 1단계로 고정하고 어른 설정에서 바꿀 수 있게만). `itemUnlock`, `photoItems` 규칙.
9. **차분하게** (`calmRules`, `calm.colorPolicy`): 색 병은 차분한 색, 칠해진 손톱만 또렷한 색. 램프는 깜빡이지 않음. 반짝임은 멈춰 있는 하이라이트.
10. 음성은 `voice` 문장과 `voice.praise`, 항상 한국어 다음 영어.

## 바꾸지 말 것
다른 놀이. 공통 규칙(누를 것 110px 이상, 한 화면 선택지 3개, 엉뚱한 곳은 응원, 소리는 누를 때만).

## 완료 기준
`tests/nailshop.js`(새로):
1. 가게 앞에서 손님을 고르면 그 손님의 손이 나옴(엄마 손 / 토토 발).
2. 1단계: 손톱 3개를 색 젤로 칠함(왼쪽 반만 칠하면 오른쪽 칸은 안 칠해져 있는지 확인) → 다음 → 램프 → 5초 뒤 윤기 상태 → 파츠 붙이기·끌어서 떼기 → 거울 → 가게 앞, 벽 액자 1개.
3. 단계를 4로 바꾸면(어른 설정 또는 테스트 훅) 갈기 → 베이스 → 색 → 굽기 → 그림 → 도장 → 파츠 → 탑젤 → 굽기 → 오일 순서가 나오고, 갈기 전후 손톱 끝 상태가 달라짐.
4. 그림 그리기에서 손톱 밖으로 그은 선이 손톱 밖에 남지 않음.
5. 거울 버튼을 누르기 전에는 끝나지 않음.
6. `tests/audit.js`에서 `nailshop` 통과, `tests/monkey.js` 오류 0건, `tests/salon.js` 통과.

## 끝나고 알려 줄 것
과정별 캡처(갈기 전후, 색 칠하는 중, 램프, 윤기, 확대해서 그리기, 파츠, 거울), 실제 기기에서 확인할 것(손톱 크기가 손가락으로 칠하기 충분한지).
