# P6. 엄마, 내 옷 넣어 주세요

**권장 모델**: 쏘넷 · **앞 단계**: P2 (단계 오르기), P3 (어른 확인)

## 왜
단계를 깨면 아이가 좋아하는 **진짜 옷과 물건**을 엄마에게 부탁해서 앱에 넣을 수 있게 합니다. 물건마다 그림을 새로 그리지 않고 사진으로 넣습니다.

## 먼저 읽을 것
`설계/config.json`(`wardrobe`), `play3.js`의 옷장(`CLOSET`, `openCloset`, `openCutout`), 옷 입히기(`play2.js`의 dressup), `salon.js`의 `WEAR`

## 할 일
1. **티켓**: `ml-levelup` 이벤트가 오면 옷 선물 티켓 1장. 홈의 토토 옆에 선물 상자 그림으로 보입니다(개수는 숫자가 아니라 상자 개수로, 최대 3개 표시).
2. **부탁 화면**: 아이가 선물 상자를 콕 하면 큰 화면에 토토와 옷걸이 그림, `askScreenVoice` 음성. 아래에 어른용 버튼 하나.
3. **어른이 넣기** (`wardrobe.parentFlow`): P3의 어른 확인 → 사진 찍기/고르기 → 자동 배경 지우기와 손보기(기존 `openCutout`) → **어디에 쓸지 고르기**: 드레스 / 머리 장식 / 목 장식 / 얼굴 장식 → 저장. 티켓 1장 사용.
4. **쓰이는 곳**:
   - 드레스: 옷 입히기에서 옷걸이 3벌 중 하나로 섞여 나옴
   - 머리·목·얼굴 장식: 미용실 5단계에서 카드 3장 중 하나로 나오고, 동물에게 그 자리에 맞춰 붙음(크기는 자리에 맞게 자동 조절)
5. **새로 들어온 것 알리기**: 다음에 그 놀이를 열면 새 물건 카드에 리본 표시와 "새 옷이 왔어요! A new dress!" 음성.
6. 예전의 "칭찬 도장 몇 개에 열림" 방식 옷장은 그대로 두되, 새로 넣는 물건은 티켓 방식으로.
7. 물건은 `wardrobe.maxItems`개까지. 넘으면 어른에게 오래된 것을 지우라고 안내.

## 바꾸지 말 것
배경 지우기 도구의 동작. 사진은 기기에만 저장.

## 완료 기준
1. 테스트용 드레스 그림과 모자 그림으로: 단계 오름 → 티켓 → 부탁 화면 → 어른 확인 → 넣기 → 옷 입히기와 미용실에 각각 나오는지.
2. 티켓이 없으면 넣기 화면으로 갈 수 없음(어른 설정에서는 티켓 없이도 넣을 수 있게 따로 둠).
3. `tests/audit.js`, `tests/monkey.js` 통과.

## 끝나고 알려 줄 것
흐름 캡처, 실제 옷 사진으로 사람이 확인해야 할 것(배경이 잘 지워지는지).
