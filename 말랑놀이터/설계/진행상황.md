# 진행 상황 (자동 진행 기록)

주인이 "적절한 모델로 끝까지 진행"을 맡겼습니다(2026-11-11). 이 문서는 어디까지 했는지 적어 두는 곳입니다.

## 진행 방식
1. 단계마다 `설계/P*.md`의 권장 모델에게 맡김(오퍼스: 새 그림과 놀이, 쏘넷: 다듬기).
2. 끝나면 검사를 다시 돌려 확인: 그 단계 테스트, `p1`, `salon`, `p2a`, `nailshop`, `p10`, `p12a`, `monkey`(6분쯤 걸림, 시간 제한 없이), 있으면 `rules`.
3. 통과하면 커밋하고, 휴대폰 링크(앱)에 올리고, 이 표를 고침.
4. 사용량 한도에 걸리면 풀리는 시각에 이어서 함.
5. 파일이 겹치지 않는 단계만 동시에 둘까지.

## 나중에 챙길 것
- 피자 1·2단계에는 아이가 고르는 순간이 없음(깊이 기준). P12-나에서 가게 앞 손님 고르기를 피자가게에도 넣으면 채워짐.
- 피자 조각 수(4·5·6), 가루 3컵·물 2컵 등은 config에 숫자 칸이 없어 코드에 있음. P2-나 때 config로 옮기기.
- 집안일의 장난감이 약 68px로 기준(110px)보다 작음. P16(틀 통일) 때 키우기.
- `tests/rules.js`의 깊이 표가 새 놀이(설거지·집안일·미로)의 `ML.__dishDepth()` 같은 훅을 읽게 하기(P16에서).
- 네일숍·피자·미로에는 별 3칸 줄과 단계 오르는 순간 화면이 아직 없음(단계는 조용히 오름). P12-나에서.
- 설거지·집안일이 어른 설정의 '놀이별 단계' 블록에 안 보임(register 필요). P16에서.
- 옷 가게: 눈 오는 날 테마에 맞는 손 소품(장갑) 없음, 빙글이 2D 뒤집기라 잠깐 얇아 보임, 거울 버튼이 치마 밑단을 조금 가림. 화장: 손거울에 비친 얼굴 없음. P16 때 다듬기.
- 조랑말 갈기는 드라이기를 오른쪽에서 댈 때 잘 보이고 왼쪽에서는 덜 보임. 콕으로 드라이 끝내기는 12~15번. 실제 기기에서 확인 필요.
- 식당: 버거(3단계)·파스타(4단계)·손님이 두 가지 주문은 아직 안 만듦. 손님이 벽 칸에 작게 보임. 물 주전자 도구가 그릇을 많이 가림.
- `tests/rules.js` 깊이 표가 새 놀이들의 깊이 훅(`__rsDepth`, `__icDepth`, `__mkDepth`, `__clDepth`, `__bakeDepth`, `__routineDepth`, `__dishDepth`, `__choreDepth`)을 읽게 고치기(P16).
- 케이크 크림 휘핑: 주인이 넣기로 결정 → P19-나.
- 직업 놀이 3~5단계(일 두 가지, 알맞은 직업 고르기, 가족 얼굴)와 집배원·농부·수의사 미완성.
- 입체감: 흰 친구(토토·콩이·구름이)는 효과가 약함, 인형 팔다리가 줄무늬처럼 보일 수 있음, 인형·화장 얼굴 머리 하이라이트가 조금 강할 수 있음. 실제 기기에서 확인 후 조정.
