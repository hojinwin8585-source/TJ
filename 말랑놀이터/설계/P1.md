# P1. 편한 터치 + 차분한 화면 + 영어 칭찬 + 소리와 동요

**권장 모델**: 쏘넷 · **대상 놀이**: 동물 미용실(`salon.js`)과 공통 도구 · **새 놀이는 만들지 않음**

## 왜
29개월 아이가 문지르기를 아직 어려워하고, 드라이기 소리를 무서워하며, 화면 색이 강합니다.

## 먼저 읽을 것
`설계/README.md`, `설계/config.json`(`calm`, `touch`, `guide`, `voice`, `sound`), `salon.js`, `guide.js`, `index.html`의 `BGM`·`say`·`sfx` 부분

## 할 일
1. **설정 읽기**: `설계/config.json`을 앱이 읽게 합니다. 오프라인에서도 되도록 같은 내용을 `config.js`(`window.MLCFG = {...}`)로 두고 `index.html`에서 가장 먼저 불러옵니다. `sw.js` 목록에 추가.
2. **문지르기 v2** (`touch.rub`): 미용실의 거품 단계에 적용하고, 다른 놀이도 쓰게 `ML.P2.makeRub(el, opts)` 공용 함수로 만듭니다.
   - 대상에 손가락이 **닿는 순간** `tapChunk`만큼 진행
   - 한 번 닿으면 손가락이 대상 밖으로 나가도 계속 셈
   - 움직인 거리로 진행. 필요한 거리 = 무대 폭 × `needStageWidths`
   - 움직이지 않고 **누르고만 있어도** 초당 `holdProgressPerSec`씩 진행
   - 효과(거품)는 손가락 바로 아래에 생기고, 도구 그림은 `brushScale`배로 크게
   - 진행은 줄어들지 않음
3. **차분한 화면** (`calm`): 색을 `calm.palette`와 `calm.choiceColors`로 바꿉니다. 미용실 배경의 물방울 무늬와 홈·공통 배경의 점 무늬를 없앱니다. 끝없이 반복되는 움직임은 안내 손과 눌러야 할 대상 하나만 남깁니다. 축하는 `calm.celebration`대로 (별·하트 6개가 천천히 떠오름). 장면 전환은 300~500ms.
4. **영어 칭찬** (`voice`): 칭찬은 `voice.praise`에서 돌아가며 한국어 다음 영어로. 장식을 고르면 `"분홍 리본! Pink ribbon!"`, 손님이 오면 `"강아지! Puppy!"`, 동작마다 `voice.actionWords`.
5. **드라이기와 샤워 소리** (`sound.dryer`, `sound.shower`):
   - 드라이기 그림에 눈과 웃는 입을 그립니다 (`스타일견본.html` 그림체).
   - 드라이 단계가 시작되면 `warnBefore`를 먼저 말합니다.
   - 아이가 눌렀을 때만 1.2초 동안 소리. 소리 크기는 사용 횟수에 따라 `volumeByUse` 순서로 (기기에 저장).
   - 소리는 `recipe`대로 WebAudio로 만듭니다. 어택 30ms 이상, 날카로운 고음 없음.
   - 어른 설정에 "드라이기 소리: 끔 / 작게 / 보통"을 추가합니다.
6. **동요 배경음** (`sound.bgm`): 지금의 `BGM`을 `songs`의 가락을 차례로 연주하게 바꿉니다. 오르골 같은 음, `volume`, `tempoBpm`, 곡 사이 쉼, 말할 때 `duckWhileSpeaking`. `pauseIn`에 있는 화면에서는 멈춤.
7. 안내 손 타이밍은 `guide` 값으로.

## 바꾸지 말 것
- 놀이 흐름(거품 → 헹굼 → 말림 → 고르기)과 카드 3장 구조
- 엉뚱한 곳을 누르면 응원하는 동작
- 다른 놀이의 동작 (색만 바뀌는 것은 괜찮음)

## 완료 기준
1. `node tests/salon.js` 통과. 그리고 **손가락을 대상에 대고 거의 움직이지 않아도** 10초 안에 거품 단계가 끝나는 테스트를 추가해서 통과.
2. `node tests/audit.js`에서 `petsalon` 통과, `node tests/monkey.js` 오류 0건.
3. `config.js`에서 `touch.rub.needStageWidths`를 바꾸면 실제로 필요한 문지르기 양이 바뀜.
4. 미용실 화면에 반복 무늬 배경이 없고, 동시에 움직이는 것이 2개 이하.
5. 드라이 단계에서 예고 음성 → 누름 → 소리 순서가 지켜짐.
