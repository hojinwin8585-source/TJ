# 말랑 놀이터 기획서

29개월 아이를 위한 터치 학습 놀이 앱입니다. 아이가 좋아하는 **동물·아이스크림·요리·음악·미술**을 소재로, 개월 수에 맞는 **선 긋기·모양 맞추기·숫자 세기·한글/영어 낱말**을 놀이처럼 익히도록 만들었습니다.

- 대상: 29개월, 말을 잘하고 영어에 관심이 많으며 음악·미술을 좋아하는 아이
- 목표: 가르치기보다 **함께 놀면서 말 걸어 주는 도구**. 성적이나 진도 압박 없음
- 형태: 광고·결제·로그인·인터넷 연결이 필요 없는 웹앱 (휴대폰/태블릿 홈 화면에 추가해서 앱처럼 사용)

### 전문가 가이드
- **WHO**: 2~4세 화면 시간 하루 1시간 이하, 짧을수록 좋음
- **AAP**: 2~5세는 양질의 콘텐츠로 하루 1시간 정도, **혼자 보게 두지 말고 함께 보기** 권장
- **Zero to Three**: 주의를 빼앗는 소리·팝업 없이, 캐릭터가 아이에게 직접 말을 걸고 새 단어를 이름 붙여 주며, 결제 유도가 없는 것을 고를 것
- **Mayo Clinic**: 어린아이는 광고와 정보를 구분하기 어려우므로 광고 없는 앱 권장

### 29개월 발달 기준 (소근육·인지)
- 25~36개월: **3~4조각 퍼즐**, 원을 보고 따라 그리기 (충북 육아자람포털, 우리아이 발달가이드북)
- 25~30개월: 동그라미 모양 낙서 → 31~36개월: **수직선 따라 그리기**, 작은 가위질 (칠곡 장난감도서관)
- 30개월 평가 항목: 구슬 꿰기, 단추 풀기, 퍼즐 조각 맞추기

→ 그래서 **선 긋기는 굵은 길·넉넉한 허용 범위**, **모양 맞추기는 2개부터 5개까지**, **숫자는 1~5부터**로 잡았습니다.

## 2. 설계 원칙 (리서치에서 뽑은 것)

1. **틀려도 벌점 없음**: 오답은 부드럽게 흔들리고 "이건 고양이야" 하고 알려 주기만 함. 실패 효과음 없음
2. **말로 이름 붙여 주기**: 누르는 모든 것에 한국어 + 영어 음성 (설정에서 한국어만/영어만 가능)
3. **광고·결제·외부 링크 0개**
4. **부모 잠금**: 설정은 톱니바퀴를 2초 꾹 눌러야 열림. 아이가 실수로 못 엶
5. **시간 제한**: 기본 15분 후 "오늘 놀이 끝!" 화면. 어른이 3초 눌러야 계속
6. **큰 버튼, 단순한 화면**: 한 화면에 한 가지 놀이, 글을 몰라도 그림만으로 진행
7. **아이 취향을 소재로**: 동물이 주인공, 아이스크림·젤리·요리가 보상

## 3. 단계별 구상

### 1단계 · 지금 (29~32개월): 탐색과 이름 붙이기 ✅ 완성

| 놀이 | 배우는 것 | 내용 |
|---|---|---|
| 🐶 **동물 친구** | 낱말, 소리, 영어 | 놀기: 12마리 동물 누르면 이름+울음소리. 찾기: "강아지 어디 있지?" 2개 중 고르기, 3번 맞히면 3개로 늘어남 |
| 🍦 **아이스크림 가게** | 색깔, 1~3 세기, 순서 | 콘/컵 고르기 → 색깔 맛 3스쿱 ("분홍 딸기, 하나!") → 토핑 → 동물 손님에게 드리기 |
| ✏️ **선 긋기** | 소근육, 손-눈 협응 | 동물을 먹이까지 데려가기. 직선 → 비스듬히 → 물결 → 지그재그 → 동그라미 (5단계) |
| 🔺 **모양 맞추기** | 도형, 공간 지각 | 웃는 얼굴 도형을 같은 자리에 끌어다 넣기. 2개 → 3개 → 4개 → 5개 |
| 🍬 **젤리 세기** | 일대일 대응, 수 세기 | 젤리를 하나씩 눌러 세기 ("하나, one"). 1~5 차례로, 익숙해지면 1~10 |
| 🎹 **동물 음악회** | 음악, 음높이 | 동물 실로폰 8음. 마음대로 치기 / 반짝반짝 작은 별: 아무 건반을 눌러도 다음 음이 나와서 아이가 항상 노래를 완성함 |
| 🎨 **그림 그리기** | 미술, 색 이름 | 10가지 색 (무지개 붓 포함), 굵기 2가지, 동물 도장. 색을 고르면 색 이름을 말해 줌 |
| 🍎 **낱말 카드** | 한글·영어 노출 | 음식/탈것/우리 집 30단어. 첫 글자(사, A)만 색으로 강조. 넘기기 또는 화살표 |

### 2단계 (32~36개월): 고르고 짝짓기
- **아이스크림 주문 받기**: 손님이 말풍선으로 "분홍 두 개 주세요" → 색과 개수 맞추기
- **동물 그림자 맞추기**: 검은 실루엣과 동물 짝짓기
- **3~4조각 그림 퍼즐**: 아이가 좋아하는 동물·디저트 그림
- **젤리 색깔 분류**: 같은 색 젤리끼리 병에 담기
- **노래 늘리기**: 곰 세 마리, 나비야 등 공개 동요 2~3곡 추가
- **우리 가족 사진 카드**: 부모가 가족·반려동물 사진을 넣으면 낱말 카드로 등장

### 3단계 (만 3세 ~ 3세 반): 소리와 규칙
- **첫소리 놀이**: "ㄱ, 기차! ㄱ, 고래!" 자음 하나에 그림 여러 개
- **알파벳 소리**: A-apple, B-ball (글자 이름보다 소리 위주)
- **패턴 이어가기**: 빨강-노랑-빨강-? 젤리 줄 세우기
- **요리 순서**: 샌드위치·컵케이크를 3단계 순서대로 만들기
- **수량 일치**: 숫자 3을 보고 젤리 3개 담기

### 4단계 (3세 반 ~ 4세): 따라 쓰기 준비
- **자모·숫자 따라 그리기**: 지금의 선 긋기 엔진을 글자 모양 길로 확장
- **간단한 더하기**: 젤리 2개 + 1개 = ?
- **이야기 순서 카드**: 그림 3장을 순서대로 놓기
- **역할 놀이 확장**: 아이스크림 가게에 돈 주고받기 (동전 1~5)

## 5. 부모님 사용 팁

- **옆에 같이 앉아서**: "아이스크림 몇 개 올렸어?", "강아지는 뭐라고 울어?" 하고 질문해 주세요. 앱보다 대화가 더 중요합니다.
- **화면 밖으로 이어 가기**: 선 긋기 다음엔 크레파스로 종이에, 젤리 세기 다음엔 진짜 간식 세기.
- **기록 보기**: 톱니바퀴 2초 꾹 → "오늘 논 놀이"에서 어떤 놀이를 몇 번 했는지 확인 (최근 14일, 이 기기에만 저장).
- **음성이 안 나오면**: 휴대폰 무음 모드를 끄고, 설정 → 접근성 → 음성 출력(TTS)에 한국어·영어 음성이 설치돼 있는지 확인하세요.
