29개월 아이를 위한 터치 학습 놀이 앱입니다. 아이가 좋아하는 **동물·아이스크림·요리·음악·미술**을 소재로, 개월 수에 맞는 **선 긋기·모양 맞추기·숫자 세기·한글/영어 낱말**을 놀이처럼 익히도록 만들었습니다.

- 대상: 29개월, 말을 잘하고 영어에 관심이 많으며 음악·미술을 좋아하는 아이
- 목표: 가르치기보다 **함께 놀면서 말 걸어 주는 도구**. 성적이나 진도 압박 없음
- 형태: 광고·결제·로그인·인터넷 연결이 필요 없는 웹앱 (휴대폰/태블릿 홈 화면에 추가해서 앱처럼 사용)

## 0. 메인 모드: 충치 세균 대작전 (퀘스트형) ✅ 완성

**주인공 = 우리 아기.** 부모가 아기 얼굴 사진을 넣으면 왕관 쓴 공주 캐릭터가 되어 지도 위를 걸어 다닙니다. 공주가 동물 친구들과 함께 곳곳에 숨은 충치 세균을 물리치는 이야기예요.

### 이야기 흐름
지도에서 반짝이는 장소를 누르면 → 공주가 길을 따라 **걸어가고** → 장소에 도착해서 **미션** → 마지막에 나타난 **세균 콕콕 잡기** → **새 동물 친구가 합류** → 다음 장소가 열림

| # | 장소 | 미션 (배우는 것) | 새 친구 |
|---|---|---|---|
| 1 | 🏠 우리 집 (욕실) | 이에 숨은 세균 4마리 콕콕 → 이가 반짝 웃음 (세기, 양치 습관) | 🐰 토끼 |
| 2 | 🚗 자동차 | 공주가 탄 자동차를 꼬불꼬불 길 따라 학교까지 (선 긋기) | 🐶 강아지 |
| 3 | 🏫 학교 | 세균이 흩어 놓은 동그라미·네모·세모 제자리에 (모양) | 🐱 고양이 |
| 4 | ⛰️ 산 | 이를 튼튼하게 하는 사과 4개 따며 세기 (숫자) | 🐻 곰 |
| 5 | 🌊 바다 | 숨은 바다 친구 찾기 "문어 어디 있지?" + 거품 속 세균 (낱말·영어) | 🐬 돌고래 |
| 6 | ✈️ 비행기 | 비행기를 구름길 따라 세균 성까지 (지그재그 선 긋기) | 🐥 병아리 |
| 7 | 🏰 세균 성 | 충치 대왕! 건반을 누를 때마다 별 마법 → '작은 별' 완성하면 대왕이 사라짐 (음악) | 🦄 유니콘 |

7곳을 다 깨면 "충치 세균 대작전 성공!" 파티. 깬 곳은 언제든 다시 할 수 있어요.

### 사진으로 캐릭터 만들기 (부모용)
- **주인공**: 처음 모험을 누르면 "주인공 만들기" 창이 떠요. 사진 넣기 → 손가락으로 얼굴을 동그라미 안에 맞추기 → 이름 입력 (예: 하은 → "하은 공주!"라고 불러 줌)
- **친구들**: 홈 → 우리 친구들 → ✏️를 2초 꾹 → 각 친구 칸에서 📷 사진. 기본은 동물이고, 가족·반려동물·애착 인형 사진으로 바꿀 수 있어요. 아직 안 만난 친구는 아이에겐 "?"로 보이고, 그 단계를 깨면 나타나요.
- 사진은 256×256 크기로 줄여서 **이 기기 브라우저 안에만** 저장돼요. 어디로도 전송되지 않아요. 브라우저 데이터를 지우면 사진도 지워지니 다시 넣어 주세요.

## 0-2. 놀이 마을 (따라하기·꾸미기·직업·소리) ✅ 완성

Babybus 류 앱에서 인기 있는 **역할 놀이 장르**(요리, 집안일, 소방관, 옷 입히기, 화장, 하루 습관)를 참고했어요. 다만 그 앱의 캐릭터·그림·음악은 쓰지 않고 모두 새로 만들었어요. 역할 놀이는 아이가 들은 말을 다시 써 보게 해서 어휘와 대화에 도움이 된다는 연구가 있어요 (대부분 상관관계 연구).

| 묶음 | 놀이 | 하는 것 (배우는 것) |

| 🏡 엄마 아빠 따라하기 | 🎂 케이크 | 맛 고르며 층 쌓기 → 과일 → 초 1~5개 세기 → 촛불 콕 불기 → 생일 축하 노래 → 칼로 쓱 잘라 4조각 → 친구들에게 나눠 주기 (색깔, 수, 나누기) |

| | 🍽️ 설거지 | 수세미로 얼룩 문지르기(거품) → 수도꼭지로 헹구기 → 건조대에 쌓기 3개 |

| | 💄 화장 놀이 | 엄마·아기·아빠 사진 또는 공주·동물 얼굴에 립스틱·볼터치·아이섀도·눈썹·반짝이·스티커, 안경·리본·왕관 같은 액세서리를 끌어다 붙이기. 물티슈로 지우기 |
| | 💅 손톱 | 엄마 손 / 아기 손. 손톱을 콕 누르면 "엄지 손톱, 분홍!" 하고 칠해짐. 반짝이·무지개·물방울, 스티커. 다 칠하면 후~ 말리기 |

> 아기상어: 핑크퐁 캐릭터나 노래를 앱 안에 그대로 넣지는 않았어요 (집에서만 써도 남의 저작물을 복제하는 건 피했어요). 대신 노래 영상 메뉴에서 **핑크퐁 공식 영상으로 바로 가는 버튼**을 넣었어요.

### 터치 많이 하는 아이를 위한 안전장치
- 두 손가락 확대, 두 번 탭 확대, 길게 눌러 나오는 메뉴, 화면 당겨서 새로고침을 막음
- 같은 메뉴를 연속으로 눌러도 한 번만 열림. 놀이마다 시작·종료 시 타이머를 정리해서 다른 화면으로 넘어가도 이전 놀이 소리가 끼어들지 않음
- 놀이 하나에서 오류가 나면 아이에게는 "처음 화면으로 왔어요"만 보이고 앱은 계속 동작
- 버튼을 누르면 이름을 말해 주고(🔊), 누른 자리에 작은 동그라미가 퍼져서 눌렸다는 걸 알 수 있음
- 자동 테스트: 무작위로 5,600번 넘게 누르고 끌고 화면을 바꿔도 오류 0건

## 2. 설계 원칙 (리서치에서 뽑은 것)

1. **틀려도 벌점 없음**: 오답은 부드럽게 흔들리고 "이건 고양이야" 하고 알려 주기만 함. 실패 효과음 없음
2. **말로 이름 붙여 주기**: 누르는 모든 것에 한국어 + 영어 음성 (설정에서 한국어만/영어만 가능)
3. **광고·결제·외부 링크 0개**
4. **부모 잠금**: 설정은 톱니바퀴를 2초 꾹 눌러야 열림. 아이가 실수로 못 엶
5. **시간 제한**: 기본 15분 후 "오늘 놀이 끝!" 화면. 어른이 3초 눌러야 계속
6. **큰 버튼, 단순한 화면**: 한 화면에 한 가지 놀이, 글을 몰라도 그림만으로 진행
7. **아이 취향을 소재로**: 동물이 주인공, 아이스크림·젤리·요리가 보상

> 퀘스트 확장 아이디어 (2단계 이후): 장소 추가 (🚂 기차 → 동물원, 🚀 로켓 → 달), 계절 지도 (눈 오는 산), 공주 옷·왕관 꾸미기 보상, 친구 목소리 녹음, 실제 양치 2분 타이머 미션.

### 2단계 (32~36개월): 고르고 짝짓기
- **아이스크림 주문 받기**: 손님이 말풍선으로 "분홍 두 개 주세요" → 색과 개수 맞추기
- **동물 그림자 맞추기**: 검은 실루엣과 동물 짝짓기
- **3~4조각 그림 퍼즐**: 아이가 좋아하는 동물·디저트 그림
- **젤리 색깔 분류**: 같은 색 젤리끼리 병에 담기
- **노래 늘리기**: 곰 세 마리, 나비야 등 공개 동요 2~3곡 추가
- **우리 가족 사진 카드**: 부모가 가족·반려동물 사진을 넣으면 낱말 카드로 등장

### 3단계 (만 3세 ~ 3세 반): 소리와 규칙
- **첫소리 놀이**: "ㄱ, 기차! ㄱ, 고래!" 자음 하나에 그림 여러 개
- **알파벳 소리**: A-apple, B-ball (글자 이름보다 소리 위주)
- **패턴 이어가기**: 빨강-노랑-빨강-? 젤리 줄 세우기
- **요리 순서**: 샌드위치·컵케이크를 3단계 순서대로 만들기
- **수량 일치**: 숫자 3을 보고 젤리 3개 담기

### 4단계 (3세 반 ~ 4세): 따라 쓰기 준비
- **자모·숫자 따라 그리기**: 지금의 선 긋기 엔진을 글자 모양 길로 확장
- **간단한 더하기**: 젤리 2개 + 1개 = ?
- **이야기 순서 카드**: 그림 3장을 순서대로 놓기
- **역할 놀이 확장**: 아이스크림 가게에 돈 주고받기 (동전 1~5)

## 5. 부모님 사용 팁

- **옆에 같이 앉아서**: "아이스크림 몇 개 올렸어?", "강아지는 뭐라고 울어?" 하고 질문해 주세요. 앱보다 대화가 더 중요합니다.
- **화면 밖으로 이어 가기**: 선 긋기 다음엔 크레파스로 종이에, 젤리 세기 다음엔 진짜 간식 세기.
- **기록 보기**: 톱니바퀴 2초 꾹 → "오늘 논 놀이"에서 어떤 놀이를 몇 번 했는지 확인 (최근 14일, 이 기기에만 저장).
- **음성이 안 나오면**: 휴대폰 무음 모드를 끄고, 설정 → 접근성 → 음성 출력(TTS)에 한국어·영어 음성이 설치돼 있는지 확인하세요.
