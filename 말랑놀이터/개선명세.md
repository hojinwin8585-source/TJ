## 1. 디자인 비평 요약

### 한 줄 평
그림과 흐름은 나아졌지만, **조작이 2세에게 너무 어렵고 화면이 무엇을 하라는지 스스로 말해 주지 않습니다.** 가장 큰 기회는 "고르는 메뉴"를 없애고 **물건 자체를 크게 만져서 바로 결과가 나오게** 하는 것입니다.

### 실제 측정 (휴대폰 폭 390px ≈ 6.5cm 기준, `tests/audit.js`)

| 화면 | 누를 수 있는 것 | 가장 작은 것 | 보통 크기 | 글자 라벨 |
|---|---|---|---|---|
| 화장 놀이 | **16개** | 0.9cm | 1.1cm | 12개 |
| 손톱 | **21개** | **0.6cm** | 1.1cm | 15개 |
| 옷 입히기 | **23개** | **0.6cm** | 1.0cm | 6개 |
| 집안일 | 11개 | 0.6cm | 0.8cm | 5개 |
| 직업 옷 | 10개 | 0.9cm | 1.1cm | 8개 |
| 출동 | 4개 | 0.6cm | 0.6cm | 4개 |
| 짝 맞추기 | 4개 | 0.8cm | 0.8cm | 1개 |
| 건물 안 (요리 마을) | 7개 | 0.9cm | 2.6cm | 0개 |

유아 권장 크기는 **2cm 이상**(NN/g)입니다. 건물 안 타일만 기준을 넘고, 나머지는 절반 수준입니다.

### 사용성 문제

| 문제 | 심각도 | 고칠 방향 |
|---|---|---|
| **꾹 누르고 있기**(밀가루·물 6.5초)를 씀. 연구에서 유아에게 가장 성공률이 낮은 동작이 길게 누르기와 두 번 누르기 | 🔴 | 콕 누르면 한 컵씩 부어지는 방식으로 |
| **점선 따라 긋기**(피자 자르기), **길 따라 끌기**(자동차·비행기). 정확한 경로가 필요 | 🔴 | 콕 누르면 칼이 천천히 알아서 굴러가는 애니메이션 |
| **도구 고르기 → 색 고르기 → 얼굴에 칠하기** 3단 구조(화장). 2세는 "도구를 고른다"는 개념이 없음 | 🔴 | 도구는 앱이 쥐여 줌. 아이는 얼굴만 만짐 |
| 버튼이 0.6~1.1cm, 한 화면에 10~23개, 가로로 밀어야 보이는 메뉴 | 🔴 | 한 화면 2~3개, 각 2cm 이상, 밀기 없음 |
| 탭(얼굴/옷/색깔/머리/소품/옷장), 켜기·끄기 같은 **글자 메뉴** | 🔴 | 글자 메뉴 삭제. 순서대로 하나씩 나오게 |
| 화장이 **자유 낙서**라서 목표도 끝도 없음. 이모지 얼굴이라 입술·볼이 어디인지 불분명 | 🟡 | 입술·볼·눈이 반짝이며 "여기!" → 콕 하면 예쁘게 채워짐 |
| 한 놀이가 너무 김 (피자 12단계, 하루 일과 8단계) | 🟡 | 5~6장면, 60~90초 |
| 화면의 글 안내(예: "꾹~ 누르고 있어요")는 아이가 못 읽음 | 🟡 | 아이 화면에서 글 삭제. 말과 움직임으로만 |
| 끌어다 놓기가 정확해야 함 (장난감 정리, 짝 맞추기, 밥 먹이기) | 🟡 | 콕 누르면 알아서 날아가거나, 끌 때 자석처럼 붙게 |
| 홈에 누를 곳이 12개 (오늘의 놀이 3 + 건물 9), 세로로 길게 밀어야 함 | 🟡 | 첫 화면은 큰 ▶ 하나 + 건물 4개 |

### 잘 되고 있는 것 (유지)
- 직접 그린 캐릭터와 음식 그림, 손님의 표정 반응
- 안내 손 시범(`guide.js`), 엉뚱한 곳을 누르면 응원, 채움 막대와 별
- 광고·결제·글 읽기 없이 한국어+영어 음성
- 문지르기 방식(설거지, 소스 바르기)은 2세에게 잘 맞음

## 2. 근거 (조사한 것)

**Khan Academy Kids (2~8세)**
- 홈에 **큰 초록 ▶ 버튼 하나**(러닝 패스)가 있고, 누르면 아이 수준에 맞는 활동이 **알아서 차례로** 나옵니다. 고르고 싶으면 따로 라이브러리로 갑니다.
- 안내 캐릭터(곰 코디 등)가 계속 등장합니다.
- 활동 형태는 몇 가지뿐입니다: **그림의 한 곳 콕 누르기, 여러 개 중 고르기, 제자리로 끌어다 놓기, 순서대로 놓기, 글자 따라 쓰기.**
- 하루 5~20분의 분량이 끝나면 기기를 내려놓도록 권합니다.
- 리뷰어는 **2~3세는 끌어다 놓기를 부모가 도와줘야 한다**고 적었습니다. 즉 Khan Kids도 2세에게는 끌기가 어렵습니다.
- 출처: [Common Sense Media](https://www.commonsensemedia.org/app-reviews/khan-academy-kids), [Khan Kids 도움말](https://khankids.zendesk.com/hc/en-us/articles/360013113232-Get-ready-for-school-with-Khan-Academy-Kids), [Khan Academy 블로그](https://blog.khanacademy.org/best-early-learning-apps-for-kids/), [활동 분석 자료(오래됨)](https://www.slideshare.net/slideshow/khan-academy-kids-teardown/123163937), [Screenwise 가이드](https://screenwiseapp.com/guides/khan-academy-kids-learning-game)
- 주의: 활동 세부는 오래된 제3자 자료에서 온 것이 섞여 있습니다. 실제 앱을 한 번 직접 해 보고 확인하세요.

**유아 터치 연구**
- 누르기와 끌기는 유아도 성공률이 높고, **두 번 누르기·길게 누르기·두 손가락 회전은 가장 낮고 오래 걸립니다** ([Nacher 외, pre-kindergarten multi-touch](https://www.researchgate.net/publication/264783987_Multi-touch_gestures_for_pre-kindergarten_children)).
- 30개월 미만은 그 이후보다 성공률이 뚜렷이 낮다는 보고가 있습니다 (수치는 원문 확인 필요).
- 2~3세는 **움직이는 손 그림 시범**이 있을 때 동작을 더 잘 따라 합니다 ([워싱턴대 연구](http://faculty.washington.edu/alexisr/TouchscreenPrompts.pdf)).
- 터치 목표는 **2cm × 2cm 이상** ([NN/g](https://www.nngroup.com/articles/children-ux-physical-development/)).
- 글 대신 음성, 틀리면 격려 → 힌트 → 정답 강조 순서 ([Sesame Workshop](https://joanganzcooneycenter.org/wp-content/uploads/2020/02/SesameWorkshop-2012.pdf)).

## 3. 만 2세 조작 규칙 (모든 화면 공통)

### 허용하는 동작 3가지
1. **콕** (한 번 누르기): 기본. 누르는 순간 0.1초 안에 소리와 움직임.
2. **쓱쓱** (아무 방향으로 문지르기): 경로·방향 상관없이 움직인 거리만 셈.
3. **쏙** (자석 끌기): 끌면 따라오고, 목표 근처(화면 폭의 1/3 이내)에서 놓거나 절반쯤 가면 **알아서 쏙** 들어감. **콕 눌러도 알아서 날아가야 함**(끌기는 선택).

### 쓰지 않는 동작
- 길게 누르기(1초 초과), 두 번 누르기, 두 손가락
- 정해진 선·길을 따라 긋기
- 가로로 밀어서 더 보기, 탭 메뉴, 켜기/끄기 스위치
- 정확한 자리에 놓아야 하는 끌기

### 화면 규칙
| 항목 | 기준 |
|---|---|
| 누를 것의 크기 | **가로세로 110px 이상** (휴대폰에서 약 1.8cm). 주인공 물건은 화면 폭의 40% 이상 |
| 한 화면의 선택지 | **최대 3개** (처음 보는 것은 2개) |
| 누를 것 사이 간격 | 16px 이상 |
| 한 동작 | 누르면 **1~2초 애니메이션**으로 결과가 보임. 빠른 연타는 무시 |
| 한 장면 | 동작 3~5번, **5~8초** |
| 한 놀이 | **5~6장면, 60~90초**, 끝나면 큰 축하 |
| 글자 | 아이 화면에 글 안내 없음. 이름표는 그림 아래 한 단어만 |
| 구석 버튼 | 집(나가기) 버튼만 작게 왼쪽 위. 놀이 영역과 떨어뜨림 |

### 진행 규칙 (이미 `guide.js`에 있음, 그대로 사용)
- 시작하면 손 그림 시범 → 2초 멈추면 다시 → 7초면 말로 → 이후 응원
- 엉뚱한 곳: 진행 없음, 응원, 손이 가리킴
- 진행도는 **물건 자체에서 보여야 함** (그릇이 차오름, 입술에 색이 채워짐) + 아래 별 막대

### 놀이 틀 4가지 (Khan Academy Kids의 활동 형태를 2세용으로)
| 틀 | 설명 | 쓰는 곳 |
|---|---|---|
| **A. 콕콕 하기** | 큰 물건 하나를 3~5번 누르면 단계적으로 변함 | 붓기, 반죽, 썰기, 자르기, 촛불 |
| **B. 쓱쓱 하기** | 큰 물건을 문지르면 채워짐 | 섞기, 소스, 설거지, 양치, 색칠 |
| **C. 쏙 넣기** | 물건 1~3개를 콕(또는 끌기) 하면 목표로 날아감 | 토핑, 장난감 정리, 밥 먹이기, 옷 입히기 |
| **D. 하나 고르기** | 큰 그림 2~3개 중 하나를 콕 | 색 고르기, 드레스 고르기, 주문 |

## 4. 화면별 개선 명세

### 4-1. 화장 놀이 (전면 재설계)
지금: 도구 8개 × 색 4개 메뉴, 이모지 얼굴에 자유 낙서, 지우개, 16개 버튼.

바꿀 것:
1. **얼굴을 새로 그림**(art.js). 큰 얼굴이 화면 폭의 85%. 입술·양 볼·눈두덩·머리 위가 각각 큰 터치 영역(110px 이상, 겹치지 않게). 아기·엄마 사진을 쓰면 사진 위에 같은 위치의 영역을 덮어씀.
2. **순서대로 한 가지씩** (메뉴 없음):
   - ① 립스틱: 큰 립스틱이 화면에 들어오고 입술이 반짝 → **입술 콕**(또는 쓱쓱) → 립스틱이 움직이며 색이 채워짐(1.5초)
   - ② 볼터치: 양 볼이 반짝 → 볼 콕, 콕 (하나, 둘)
   - ③ 눈 화장: 눈두덩 콕, 콕
   - ④ 장식: 큰 그림 3개(왕관·리본·꽃) 중 **하나 고르기** → 머리 위로 날아감
   - ⑤ 거울: 얼굴이 웃고 반짝, "예쁘다!" 박수
3. 색 고르기는 ① 앞에 **큰 립스틱 3개 중 하나 고르기**로 한 번만.
4. 지우개, 가로 스크롤, 위쪽 작은 버튼 3개 삭제. 다시 하려면 끝 화면의 큰 🔄 하나.

### 4-2. 손톱
지금: 작은 손톱 5개(0.6cm), 색 9개 + 스티커 4개 가로 스크롤, 엄마 손/아기 손 탭.

바꿀 것:
1. 시작: **매니큐어 병 3개 중 하나 고르기** (각 110px 이상).
2. **손가락 하나씩 크게**: 손톱이 화면 폭의 40%. 손톱 콕(또는 쓱쓱) → 붓이 지나가며 칠해짐 → 다음 손가락이 들어옴. "하나, 둘 … 다섯".
3. 다 칠하면 손 전체가 보이고, 스티커 3개 중 하나 고르기 → 모든 손톱에 붙음 → 후~ 말리기는 손을 콕.
4. 엄마 손/아기 손 탭 삭제 (번갈아 자동).

### 4-3. 공주 왕자 옷 입히기
지금: 탭 6개, 한 탭에 5~14개, 23개 버튼.

바꿀 것:
1. **옷걸이 3벌 중 하나 고르기** → 인형이 빙그르르 돌며 입음.
2. **왕관·머리 장식 3개 중 하나** → **손에 드는 것 3개 중 하나** → 거울과 찰칵.
3. 매번 3개는 전체 목록에서 돌아가며 나옴 (색·무늬 조합은 앱이 미리 만든 드레스로).
4. 도장으로 연 **우리 집 드레스**는 옷걸이 3벌 중 하나로 섞여 나옴.
5. 얼굴 고르기는 맨 처음 **3개 중 하나**(우리 아기·엄마·공주)로만. 나머지 얼굴은 어른 설정으로.

### 4-4. 말랑 피자가게 (조작 단순화)
지금: 12단계. 꾹 누르기 2번, 왔다 갔다, 점선 긋기 3번.

바꿀 것 (7장면, 모두 콕 또는 쓱쓱):
| 장면 | 동작 | 내용 |
|---|---|---|
| 주문 | (보기) | 손님이 그림으로 주문. 말풍선이 크게 |
| 가루와 물 | 콕 × 3, 콕 × 2 | **밀가루 봉지가 그릇 위에 떠 있고, 봉지(또는 그릇)를 콕** 하면 한 컵이 1.5초 동안 쏟아짐. 물병도 같은 방식 |
| 반죽 | 쓱쓱 | 그릇을 문지르면 섞이고 덩어리가 됨. (섞기와 치대기를 하나로) |
| 펴기 | 콕 × 4 | 반죽을 콕 누를 때마다 밀대가 한 번 굴러가며 넓어짐 |
| 소스와 치즈 | 쓱쓱, 콕 × 5 | 문지르면 소스, 이어서 콕콕 하면 치즈 |
| 토핑 | 콕 × 6 | 주문한 재료가 차례로 손에 들려 있고, 피자를 콕 하면 올라감. **썰기는 토토가 옆에서 써는 모습을 보여 주기만** |
| 굽고 자르기 | 콕, 콕 × 3 | 화덕 콕 → 구워짐. 피자 콕 → **피자 칼이 1.2초 동안 천천히 알아서 굴러가며** 한 줄. 세 번 |
| 드리기 | 콕 | 손님이 먹고 반응 |

- `makePour`의 길게 누르기 방식과 점선 긋기(`wheel`)는 삭제.
- 연타 방지: 한 번 누르면 애니메이션이 끝날 때까지(1.2~1.5초) 다음 입력을 받지 않음. 이것으로 "너무 빨리 넘어감"을 해결.

### 4-5. 빵 굽기, 케이크
- 피자가게와 **같은 틀**로 다시 만듦 (손님 주문, 직접 그린 그림, 가운데 한 군데, 채움 막대).
- 위쪽 작은 재료 버튼(0.9cm)과 글자 단계 표시 삭제.
- 빵: 가루와 우유 콕 → 반죽 쓱쓱 → 동글동글 콕 × 4 → 화덕 콕 → 나눠 주기 콕 × 4
- 케이크: 달걀 콕 × 3 → 거품 쓱쓱 → 굽기 콕 → 크림 쓱쓱 → 과일 콕 × 5 → 촛불 콕 × 3 → 생일 노래

### 4-6. 그 밖의 놀이
| 놀이 | 바꿀 것 |
|---|---|
| 설거지 | 문지르기는 유지. 수도꼭지 버튼(0.9cm)을 없애고 다 닦으면 물이 알아서 나옴. 접시 3개 → 2개 |
| 집안일 | 탭 4개 삭제, 하나가 끝나면 다음으로. 장난감은 **콕 누르면 상자로 날아감**. 빨래 3바구니 분류 → 바구니 하나에 쏙 |
| 하루 일과 | 8장면 → 4장면(일어나기, 양치, 밥, 잠). 밥 먹이기는 음식을 콕 |
| 직업 옷 | 가로 스크롤 8개 → **직업 카드 3개 중 하나**, 고르면 옷이 입혀지고 탈것이 지나감 |
| 짝 맞추기 | 끌기 → 탈것이 가운데 크게 나오고 **사람 2명 중 하나 고르기** |
| 출동 | 위 탭(0.6cm) 삭제, 세 가지가 차례로. 물 뿌리기(문지르기)는 유지 |
| 공주 모험 | 길 따라 끌기 → 탈것을 콕 할 때마다 한 칸씩 전진. 모양 맞추기 → 조각을 콕 하면 제자리로 |
| 배움 학교 | 젤리 세기(콕)는 유지하되 젤리를 110px 이상으로, 한 번에 최대 5개. 낱말 카드는 화살표를 크게, 점 목록 삭제 |

### 4-7. 홈과 건물 안
- **첫 화면에 다 보이게**(세로로 밀지 않음): 위에 토토 + **아주 큰 ▶ 하나**(오늘의 놀이, 화면 폭 40% 이상). 아래에 건물 4개(2 × 2, 각 화면 폭 44%).
  - 건물 4개: 요리 마을, 꾸미기 살롱, 공주 모험, 노래 극장. 직업·배움·친구들·도장은 두 번째 화면(큰 화살표로 이동)이나 요리/살롱 안으로.
- ▶를 누르면 Khan Academy Kids의 러닝 패스처럼 **놀이 3개가 차례로** 이어지고, 끝나면 도장과 "오늘 놀이 끝" 화면.
- 건물 안: 한 화면에 **타일 4개까지**, 이모지 대신 직접 그린 그림.

## 4-8. 그림 방향: 더 예쁘고 귀엽게 (필수)

아이들은 예쁘고 귀여운 그림에 먼저 손이 갑니다. 지금은 대부분의 화면이 **이모지 + 단색 배경**이라 단순하고 허전합니다.
**`스타일견본.html`을 브라우저로 열면** 기준 그림이 모두 보입니다. 새 그림은 반드시 이 견본과 같은 그림체로 그립니다.

### 이미 그려 둔 것 (`art.js`, 바로 쓸 수 있음)
| 함수 | 내용 |
|---|---|
| `ART.animal(kind, mood, opt)` | 토토·보리·모모·콩이. 큰 머리, 반짝 눈, 발그레 볼, 명암. 표정 6가지. `opt`: `bow`, `chef`, `apron`, `wave` |
| `ART.face(state)` | **화장 놀이용 얼굴**. `state`: `lip`(색), `blushL/R`, `lidL/R`(색), `acc`(crown·ribbon·flower), `mood`, `glow`(반짝일 곳) |
| `ART.FACE_ZONES` | 얼굴에서 누를 곳의 위치와 크기 (`lips`, `cheekL/R`, `lidL/R`, `top`). 좌표는 0~300 × 0~330 |
| `ART.dress(kind, 색1, 색2)` | 드레스 3종: `ball`(공주 드레스), `tutu`(발레복), `star`(별 원피스) |
| `ART.ACC`, `ART.accSVG(name)` | 왕관, 리본, 꽃, 요술봉, 별, 하트 |
| `ART.lipstick(색)`, `ART.polish(색)` | 립스틱, 매니큐어 병 |
| `ART.twinkle`, `ART.star` | 반짝이, 별 (장식용) |

### 그림체 규칙
1. **비율**: 머리가 몸보다 크게(2등신). 모서리는 모두 둥글게.
2. **얼굴**: 큰 눈에 흰 반짝점 2개(큰 것 위, 작은 것 아래), 분홍 볼은 번지는 그라데이션, 작은 입.
3. **입체감**: 단색으로 칠하지 말고 위는 밝고 아래는 살짝 어둡게. 윗부분에 흰 윤기 한 줄. 발밑에 옅은 그림자.
4. **선**: 외곽선은 모두 갈색 `#5B3A29`, 굵기 3.5. 검정 선은 쓰지 않음.
5. **색**: 파스텔 바탕(분홍 `#FFF3F8`, 하늘 `#EAF6FF`, 크림 `#FFF7D6`)에 포인트는 분홍 `#FF6F91`·노랑 `#FFC93C`·보라 `#9A7BFF`·하늘 `#5EC2FF`.
6. **배경은 세 겹**: 뒤(벽·하늘·바닥), 가운데(가구·거울·창문), 앞(가랜드·리본·반짝이). **한 장면에 꾸밈 요소 3개 이상.** 빈 단색 화면 금지.
7. **움직임**: 캐릭터는 눈 깜빡임과 숨쉬듯 통통. 누르면 말랑하게 눌렸다 튀어나옴. 성공하면 반짝이와 하트가 퍼짐.
8. **이모지 금지**: 아이가 보는 화면의 이모지는 모두 직접 그린 그림으로 바꿈. (지금 남은 곳: 건물 안 타일, 빵·케이크, 설거지, 집안일, 하루 일과, 직업, 옷 입히기, 손톱, 소리 놀이, 배움 놀이, 공주 모험 지도와 세균, 오늘의 놀이 동그라미)

### 화면별로 더 그려야 할 것
| 화면 | 필요한 그림 |
|---|---|
| 꾸미기 살롱 | 거울과 화장대 배경, 가랜드, 인형 몸(드레스 입는), 손과 손톱(큰 것), 신발·가방 |

### 지켜야 할 것
- 화면을 나갈 때 타이머가 남지 않게 `life(id)`의 `L.later`만 사용 (그냥 `setTimeout`으로 다음 장면을 부르지 말 것. 실제로 이 때문에 오류가 났었음).
- 터치는 `pointerdown`에서 바로 반응. `pointerId`는 0일 수 있으니 `!== null`로 비교.
- 말은 `say(한국어, 영어)`. 조사(을/를, 이/가)는 받침에 맞출 것.
- 새 그림은 `art.js`에 같은 외곽선(`#5B3A29`, 굵기 3.5)으로.
- 다른 앱(핑크퐁, Babybus, Khan Academy Kids)의 캐릭터·그림·노래는 넣지 않음. 활동 방식만 참고.
