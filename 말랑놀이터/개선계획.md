# 말랑 놀이터 개선 계획안

29개월 아이가 **혼자서도 끝까지 해낼 수 있게** 만드는 것이 목표입니다.
피자가게에 먼저 적용했고(1차 완료), 같은 규칙을 나머지 놀이에 차례로 적용합니다.

---

## 1. 무엇이 문제였나 (다른 유아 앱과 비교)

| # | 지금까지의 문제 | 잘 만든 유아 앱은 | 고친 방향 |
|---|---|---|---|
| 1 | 단계마다 눌러야 하는 곳이 달랐어요 (아래 도구 버튼 → 위 그릇 → 다시 아래 버튼) | Sago Mini, Toca: 화면 가운데 큰 대상 하나만 만져요 | **한 군데 터치**: 가운데 큰 대상(그릇, 반죽, 피자)만 눌러요. 다른 곳을 누르면 응원하며 알려 줘요 |
| 2 | 뭘 해야 하는지 글과 말로만 알려 줬어요 | 손 그림이 동작을 먼저 보여 줘요 (연구: 유아는 말만 하면 자주 놓치고, 만화 손 시범이 효과적) | **안내 손**이 먼저 시범 |
| 3 | 아이가 멈춰도 앱이 가만히 있었어요 | 2~5초 가만히 있으면 다시 알려 줘요 | **2초** 뒤 손 다시 → **7초** 뒤 말로 한 번 더 → 그 뒤에는 **응원** (대신 해 주지 않음) |
| 4 | 얼마나 했는지, 언제 끝나는지 안 보였어요 | 채워지는 막대나 별 | **채움 막대 + 별** (다 차면 별이 켜져요) |
| 5 | 밀가루·물은 15초, 나머지는 2~3초로 들쭉날쭉했어요 | 한 동작이 5~8초로 고르게 | 모든 단계 **약 6~8초** |
| 6 | 정확히 해야만 인정됐어요 (그릇 위에서만, 가운데를 지나가게, 동그랗게) | 대충 해도 되는 넉넉한 판정 | 문지르기·누르기·움직인 거리만 세요 |
| 7 | 고르는 버튼이 많았어요 (토핑 그릇 4개 + 굽기 버튼) | 한 번에 하나만 | 토핑은 주문한 것을 순서대로 4개씩 |

근거: Sesame Workshop 태블릿 설계 가이드(글 대신 음성, 단계적으로 도와주기), 워싱턴대 유아 터치 안내 연구(손 그림 시범), 유아 터치 설계 프레임워크(3~5초 뒤 다시 안내, 음성은 그림과 함께), NN/g(큰 터치 목표).

## 1-2. 실제 유아 앱에서 가져온 것 (Babybus · 토도 · 베베핀)

| 앱 | 주된 좋은 점 | 말랑 놀이터에 반영 |
|---|---|---|
| **베베핀 타운** | 주인공과 함께 **공간(거실·부엌·욕실…)을 돌아다니며** 놀아요. 양치·목욕·요리·정리 같은 생활 놀이, 동요 영상 | 홈을 목록에서 **마을 그림**으로 (성, 요리 마을, 살롱, 직업 마을, 학교, 극장, 친구들 집). 건물마다 동물 친구가 서 있어요 ✅ |
| **토도 (수학·한글·영어)** | **오늘 할 분량**을 정해서 보여 주는 데일리 코스, 게임처럼 반복, 부모 리포트 | 홈 맨 위 **오늘의 놀이 3개**. 다음 할 놀이가 크게 반짝이고 "여기!" 표시, 끝낸 건 초록 체크 ✅ |
| **Babybus (아기 팬더의 세상)** | 글 없이 **그림과 말**로 안내, 영역을 5~6개로 나눔, 주인공 캐릭터(키키·묘묘)가 계속 등장 | 건물 5개 + 모험 성, 안내 캐릭터 **토토**가 홈에서 인사하고 오늘 놀이를 말로 알려 줘요 ✅ |
| 공통 | 틀려도 혼내지 않고, 정확한 곳을 눌렀을 때만 진행 | **아무 데나 눌러도 진행되던 것을 없애고**, 엉뚱한 곳을 누르면 응원 + 손이 가리켜 줘요. 대신 해 주기도 없앴어요 ✅ |

아직 남은 것: 건물 안 놀이 고르는 화면과 대부분의 놀이는 예전 그림(이모지) 그대로예요. 아래 순서대로 바꿉니다.

## 2. 말랑 놀이 규칙 7가지 (모든 놀이에 적용)

1. **한 화면, 한 군데, 한 동작**. 큰 대상 하나만 만지면 돼요.
2. **먼저 보여 주기**. 단계가 시작되면 손 그림이 동작을 시범해요.
3. **2초 규칙**. 2초 멈추면 손이 다시 나오고, 7초면 말로 다시 알려 주고, 그 뒤에는 응원해 줘요. 대신 해 주지는 않아요.
4. **채움 막대**. 지금 얼마나 했는지 항상 보여요. 다 차면 별.
5. **6~8초 리듬**. 너무 길지도 짧지도 않게.
6. **혼내지 않기**. 엉뚱한 곳을 누르면 "여기야, 할 수 있어!" 하고 응원하며 손이 가리켜 줘요. 맞는 곳을 눌러야 진행돼요.
7. **동작은 5가지만**: 콕(누르기), 꾹(누르고 있기), 쓱쓱(문지르기), 빙글빙글, 왔다 갔다.

## 3. 1차 완료: 말랑 피자가게

| 단계 | 동작 | 전 | 후 |
|---|---|---|---|
| 밀가루 | 꾹 | 15초, 그릇 위에서만 | 6.5초, 어디든 |
| 물 | 꾹 | 15초 | 6.5초 |
| 섞기 | 빙글빙글 | 정확히 원을 그려야 함 | 움직이기만 하면 됨 (약 7초) |
| 반죽 | 콕콕 | 6번 | 8번 |
| 밀대 | 왔다 갔다 | 방향 전환 5번 | 움직인 만큼 (약 7초) |
| 소스 | 쓱쓱 | 78% 칠해야 | 70%, 붓 더 크게 |
| 치즈 | 콕콕 | 16번 | 22번 |
| 썰기 | 콕, 콕 | 3번씩, 연타 가능 | 5번씩, 한 번 썰 때마다 칼이 내려오고 잠깐 쉬어요 |
| 토핑 | 콕콕 | 그릇 고르기 + 굽기 버튼 | 주문한 것 4개씩, 버튼 없음 |
| 굽기 | 콕 | 아래 버튼 2번 | 아무 데나 콕 (넣기, 꺼내기) |
| 자르기 | 쓱~ | 가운데를 지나가게 긋기 2번 | **점선을 따라 긋기** 3번 → 6조각 (약 15초) |
| 드리기 | 콕 | 아래 버튼 | 피자를 콕. 다음 손님은 노란 벨을 콕 |

자동 테스트 결과: 엉뚱한 곳을 4번 눌러도 진행되지 않고 응원 4번, 30초 그냥 두어도 그대로. 맞는 곳을 누르면 한 판 완성. 단계별 약 6~8초, 피자 자르기 약 15초.

## 4. 앞으로의 순서

| 차수 | 대상 | 할 일 |
|---|---|---|
| 홈 (완료) | 마을 그림 홈, 오늘의 놀이, 안내 캐릭터 토토 | ✅ |
| **2차** | 건물 안 화면 + 빵 굽기, 케이크 | 피자가게와 같은 틀(손님 주문, 직접 그린 그림, 안내 손, 채움 막대)로 다시 만들기 |
| **3차** | 공주 모험 7곳 | 각 미션에 안내 손과 채움 막대, 세균 잡기에 손 시범, 그림을 이모지에서 직접 그린 그림으로 |
| **4차** | 꾸미기 살롱 (옷, 화장, 손톱) | 고르는 것을 3개 이하로, 드레스 직접 그리기, 안내 손 |
| **5차** | 배움 학교 (동물, 젤리, 모양, 선 긋기, 낱말) | 안내 손, 틀려도 다음으로 가는 도움 사다리 (격려 → 힌트 → 정답 반짝) |
| **6차** | 직업 마을, 하루 일과, 집안일 | 끌어다 놓기를 "콕 누르면 알아서 감"으로 바꾸기 |
| 마지막 | 전체 | 아이 반응을 보고 시간(6~8초)과 도움 타이밍(2·7·11초) 조정 |

## 5. 아이가 할 때 봐 주세요 (다음 개선의 재료)

- 손 그림 시범을 보고 **따라 하나요?** 아니면 손 그림 자체를 누르려고 하나요?
- 어느 단계에서 **멈추거나 다른 데를 누르나요?**
- 6~8초가 **지루해 보이는 단계**와 **더 하고 싶어 하는 단계**는 어디인가요?
- 채움 막대와 별을 **쳐다보나요?**
- 대신 해 주기(11초)가 나오기 전에 **스스로 다시 시작하나요?**
